Projeto Analisador de Texto

Quantas palavras tem esse texto? Qual palavra eu mais repito? Neste projeto você vai escrever um programa que lê um arquivo de texto e responde a essas perguntas, em sete etapas. No caminho aparece uma surpresa que todo programador de língua portuguesa encontra um dia: para o computador, café tem 5 "letras". Você vai entender por quê, contar do jeito certo e conferir cada número com o wc, o contador de palavras do Linux.

Você vai praticar
  • Ler um arquivo linha por linha (arquivos e getline) e tratar o arquivo que não existe.
  • A diferença entre bytes e caracteres no UTF-8 (Acentos e UTF-8).
  • Separar palavras com std::istringstream e limpar a pontuação com <cctype>.
  • Contar cada palavra com std::map e ordenar pela contagem com std::sort e uma lambda.
  • Um relatório com std::format e um programa que recebe o nome do arquivo na linha de comando.

Todos os programas foram compilados e executados na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/cpp/texto, com o g++ 15.2 e o comando padrão do guia. O programa fica num arquivo só, analisar.cpp. Nas caixas Experimente, o texto está numa aba ao lado do código: você pode trocá-lo pelo seu.

Etapa 2 · Bytes × caracteres

Quantas letras tem a palavra café? Quatro. Pergunte ao C++ com std::string("café").size() e ele responde 5. Veja os bytes do arquivo com o od (octal dump, aqui em hexadecimal) e conte com o wc, que tem -c para bytes e -m para caracteres:

$ printf 'café' | od -An -tx1
 63 61 66 c3 a9
$ printf 'café' | wc -c
5
$ printf 'café' | wc -m
4

c, a e f ocupam um byte cada (63 61 66). O é ocupa dois: c3 a9. É a codificação UTF-8, a do Linux, da web e deste guia. Ela guarda cada caractere em 1 a 4 bytes, e o primeiro byte diz quantos vêm:

Bits do byteTeste em C++SignificaExemplo
0xxxxxxxc < 0x80Caractere de 1 byte (os do inglês, números, pontuação).a = 61
110xxxxx(c & 0xE0) == 0xC0Começo de um caractere de 2 bytes.é = c3 a9
1110xxxx(c & 0xF0) == 0xE0Começo de um caractere de 3 bytes.€ = e2 82 ac
11110xxx(c & 0xF8) == 0xF0Começo de um caractere de 4 bytes (emojis).😀 = f0 9f 98 80
10xxxxxx(c & 0xC0) == 0x80Continuação: o 2º, 3º ou 4º byte de um caractere.o a9 do é

Daí a receita: para contar caracteres, conte os bytes que não são de continuação. O & (E bit a bit) com 0xC0 (11000000) guarda só os dois primeiros bits do byte; se eles forem 10 (0x80), é continuação.

#include <fstream>
#include <iostream>
#include <string>

// Quantos caracteres (não bytes) um texto em UTF-8 tem.
std::size_t contarCaracteres(const std::string& texto) {
    std::size_t n = 0;
    for (unsigned char c : texto) {
        if ((c & 0xC0) != 0x80) {     // não é byte de continuação
            ++n;
        }
    }
    return n;
}

int main() {
    std::ifstream arq{"texto.txt"};
    if (!arq) {
        std::cerr << "Não consegui abrir texto.txt\n";
        return 1;
    }

    int linhas = 0;
    std::size_t bytes = 0, caracteres = 0;
    std::string linha;
    while (std::getline(arq, linha)) {
        ++linhas;
        std::cout << linhas << ": " << linha.size() << " bytes, "
                  << contarCaracteres(linha) << " caracteres\n";
        bytes += linha.size() + 1;                    // +1: o '\n' que o getline tirou
        caracteres += contarCaracteres(linha) + 1;
    }
    std::cout << "Linhas: " << linhas << '\n';
    std::cout << "Caracteres: " << caracteres << '\n';
    std::cout << "Bytes: " << bytes << '\n';
}
TrechoO que faz
for (unsigned char c : texto)Percorre o texto byte a byte. unsigned char vê o byte como um número de 0 a 255; com char (que no Linux x86-64 tem sinal), o c3 viraria −61. Veja char.
(c & 0xC0) != 0x80"Não é byte de continuação": começa um caractere novo.
std::size_tO tipo sem sinal que o C++ usa para tamanhos (o mesmo de size()).
linha.size() + 1O getline tira o \n do fim de cada linha, mas ele ocupa um byte (e é um caractere) no arquivo. Somamos de volta.

Caractere não é o mesmo que "letra que você vê"

Esta contagem é a de pontos de código, a mesma do wc -m. Na maioria dos textos em português ela coincide com as letras que você vê. Mas há casos em que não: um é pode ser gravado como e + um acento "solto" (dois pontos de código) e alguns emojis são vários pontos de código juntos. Para esses casos existem bibliotecas especializadas, como a ICU. Mais em Acentos e UTF-8.

Etapa 3 · Contar as palavras

O que é uma palavra? Para começar, a mesma definição do wc: um pedaço de texto entre espaços. O C++ já sabe separar assim: o >> de um fluxo pula os espaços e lê até o próximo espaço. Para usar o >> numa std::string, transformamos a linha num fluxo com std::istringstream (input string stream, de <sstream>):

#include <fstream>
#include <iostream>
#include <sstream>
#include <string>

// Quantos caracteres (não bytes) um texto em UTF-8 tem.
std::size_t contarCaracteres(const std::string& texto) {
    std::size_t n = 0;
    for (unsigned char c : texto) {
        if ((c & 0xC0) != 0x80) {     // não é byte de continuação
            ++n;
        }
    }
    return n;
}

int main() {
    std::ifstream arq{"texto.txt"};
    if (!arq) {
        std::cerr << "Não consegui abrir texto.txt\n";
        return 1;
    }

    int linhas = 0;
    std::size_t bytes = 0, caracteres = 0, palavras = 0;
    std::string linha;
    while (std::getline(arq, linha)) {
        ++linhas;
        bytes += linha.size() + 1;
        caracteres += contarCaracteres(linha) + 1;

        std::istringstream fluxo{linha};
        std::string palavra;
        while (fluxo >> palavra) {
            ++palavras;
        }
    }
    std::cout << "Linhas: " << linhas << '\n';
    std::cout << "Palavras: " << palavras << '\n';
    std::cout << "Caracteres: " << caracteres << '\n';
    std::cout << "Bytes: " << bytes << '\n';
}
TrechoO que faz
std::istringstream fluxo{linha};Um "cin de mentira" que lê de dentro da linha.
while (fluxo >> palavra)Lê a próxima palavra; quando a linha acaba, o laço termina. Espaços repetidos e tabulações são pulados.

Etapa 4 · Contar cada palavra

Para saber quantas vezes cada palavra aparece, um std::map da palavra para a contagem: std::map<std::string, int>. O truque é ++contagem[palavra]: se a palavra é nova, o [] a cria com 0 e o ++ faz 1; se já existe, soma 1. (Aqui o [] criar a chave é exatamente o que queremos, ao contrário do estoque.) Primeira tentativa, sem limpar nada:

#include <fstream>
#include <iostream>
#include <map>
#include <sstream>
#include <string>

int main() {
    std::ifstream arq{"texto.txt"};
    if (!arq) {
        std::cerr << "Não consegui abrir texto.txt\n";
        return 1;
    }

    std::map<std::string, int> contagem;
    std::string linha;
    while (std::getline(arq, linha)) {
        std::istringstream fluxo{linha};
        std::string palavra;
        while (fluxo >> palavra) {
            ++contagem[palavra];
        }
    }

    std::cout << contagem.size() << " palavras diferentes:\n";
    int i = 0;
    for (const auto& [palavra, vezes] : contagem) {
        std::cout << palavra << '=' << vezes << ' ';
        if (++i % 8 == 0) {
            std::cout << '\n';
        }
    }
    std::cout << '\n';
}

FunçãoPergunta ou fazExemplo
std::isalnum(c)É letra ou número? (alphanumeric)'a' sim, ',' não
std::isalpha(c)É letra?'7' não
std::ispunct(c)É pontuação?'!' sim
std::tolower(c)Devolve a minúscula.'A' → 'a'

Essas funções só entendem um byte por vez, e só os caracteres do inglês. Por isso a nossa limpar guarda as letras e números e todo byte de 0x80 para cima (os pedaços das letras acentuadas), sem tentar mexer neles:

#include <cctype>
#include <fstream>
#include <iostream>

            limpa += static_cast<char>(std::tolower(c));
        }
    }
    return limpa;
}

#include <cctype>
#include <format>
#include <fstream>
#include <iostream>
#include <map>
#include <sstream>
#include <string>
#include <utility>
#include <vector>

// Quantos caracteres (não bytes) um texto em UTF-8 tem.
std::size_t contarCaracteres(const std::string& texto) {
    std::size_t n = 0;
    for (unsigned char c : texto) {
        if ((c & 0xC0) != 0x80) {     // não é byte de continuação
            ++n;
        }
    }
    return n;
}

// Tira a pontuação e passa para minúsculas (só as letras sem acento).
std::string limpar(const std::string& palavra) {
    std::string limpa;
    for (unsigned char c : palavra) {
        if (std::isalnum(c) || c >= 0x80) {
            limpa += static_cast<char>(std::tolower(c));
        }
    }
    return limpa;
}

int main(int argc, char* argv[]) {
    std::string nome = argc > 1 ? argv[1] : "texto.txt";
    std::ifstream arq;
    if (nome != "-") {                     // "-" quer dizer: ler do teclado
        arq.open(nome);
        if (!arq) {
            std::cerr << "Não consegui abrir " << nome << '\n';
            return 1;
        }
    }
    std::istream& entrada = (nome == "-") ? std::cin : arq;

    int linhas = 0;
    std::size_t bytes = 0, caracteres = 0, palavras = 0;
    std::map<std::string, int> contagem;
    std::string maisLonga;

    std::string linha;
    while (std::getline(entrada, linha)) {
        ++linhas;
        bytes += linha.size() + 1;                    // +1: o '\n' que o getline tirou
        caracteres += contarCaracteres(linha) + 1;

        std::istringstream fluxo{linha};
        std::string palavra;
        while (fluxo >> palavra) {
            ++palavras;
            std::string limpa = limpar(palavra);
            if (limpa.empty()) {
                continue;
            }
            ++contagem[limpa];
            if (contarCaracteres(limpa) > contarCaracteres(maisLonga)) {
                maisLonga = limpa;
            }
        }
    }

    std::vector<std::pair<std::string, int>> ranking(contagem.begin(), contagem.end());
    std::sort(ranking.begin(), ranking.end(), [](const auto& a, const auto& b) {
        if (a.second != b.second) {
            return a.second > b.second;               // mais vezes primeiro
        }
        return a.first < b.first;                     // empate: ordem alfabética
    });

    std::cout << std::format("Análise de {}\n\n", nome);
    std::cout << std::format("{:<20}{:>6}\n", "Linhas", linhas);
    std::cout << std::format("{:<20}{:>6}\n", "Palavras", palavras);
    std::cout << std::format("{:<20}{:>6}\n", "Palavras diferentes", contagem.size());
    std::cout << std::format("{:<20}{:>6}\n", "Caracteres", caracteres);
    std::cout << std::format("{:<20}{:>6}\n", "Bytes", bytes);
    std::cout << std::format("\nPalavra mais longa: {} ({} letras)\n", maisLonga,
                             contarCaracteres(maisLonga));

    std::cout << "\nMais frequentes:\n";
    for (std::size_t i = 0; i < ranking.size() && i < 5; ++i) {
        const auto& [palavra, vezes] = ranking[i];
        std::cout << std::format("{:>2}. {:<10}{:>3} {}\n", i + 1, palavra, vezes,
                                 std::string(vezes, '#'));
    }
}

Desafios extras

  1. Maiúsculas acentuadas. Faça Às virar às. Dica: em UTF-8, as maiúsculas acentuadas do português são c3 80 a c3 9d, e a minúscula é o segundo byte + 0x20 (À = c3 80, à = c3 a0).
  2. Palavras vazias. Ignore "a", "o", "e", "de", "do", "da", "um" no ranking, guardando-as num std::set.
  3. Palavras com hífen. "guarda-chuva" vira "guardachuva". Mantenha o hífen quando ele estiver entre letras.
  4. Arquivos do Windows. Linhas terminadas em \r\n deixam um \r no fim de cada linha lida pelo getline, e os bytes contados mudam. Detecte e remova.
  5. Vários arquivos. ./analisar a.txt b.txt c.txt: um relatório para cada um (um laço em argv) e um total no fim, como o wc faz.
  6. Ordem alfabética de gente. Faça "lápis" vir antes de "lojinha" comparando as palavras sem acento (troque á por a só para comparar).

Resumo

  • std::ifstream arq{nome}; + if (!arq): um arquivo que não abriu não lança exceção, só fica em falha. Confira sempre; avise em std::cerr e saia com return 1.
  • while (std::getline(arq, linha)) lê linha por linha, sem o \n.
  • Em UTF-8, um caractere tem de 1 a 4 bytes. size() conta bytes; para contar caracteres, conte os bytes com (c & 0xC0) != 0x80, usando unsigned char. Confira com wc -c e wc -m.
  • std::istringstream + >> separa palavras por espaços, como o wc -w; a pontuação vem grudada.
  • <cctype> (isalnum, tolower) só entende os caracteres do inglês: preserve os bytes ≥ 0x80.
  • ++contagem[palavra] num std::map<std::string, int> conta ocorrências; para ordenar por contagem, copie para um vector de pair e use std::sort com uma lambda que desempata.
  • int main(int argc, char* argv[]) recebe a linha de comando; std::istream& deixa o mesmo código ler de arquivo ou do teclado.
