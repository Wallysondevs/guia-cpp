Projeto Controle de Estoque

A lojinha de papelaria da Ana cresceu, e o caderno onde ela anotava o estoque não dá mais conta: ela vende cadernos sem perceber que estão acabando e não sabe quanto dinheiro está parado na prateleira. Neste projeto você vai escrever, em sete etapas, o programa que ela precisa: guarda os produtos pelo nome, registra entradas e saídas, avisa quando algo está acabando, mostra um relatório do que vale mais e grava tudo num arquivo, para nada se perder quando o programa fecha.

Você vai praticar
  • struct para descrever um produto.
  • std::map: guardar e achar produtos pelo nome (find, [], e a armadilha do []).
  • std::optional: uma busca que pode não encontrar nada.
  • for de intervalo com desestruturação (auto& [nome, p], de pair e tuple).
  • std::sort com uma lambda que diz a ordem.
  • Gravar e ler um arquivo CSV (arquivos), convertendo texto em número (stoi e stod).
  • Um menu de comandos digitados pelo usuário.

Todos os programas foram compilados e executados na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/cpp/estoque, com o g++ 15.2 e o comando padrão do guia, g++ -std=c++23 -Wall -Wextra estoque.cpp -o estoque. O programa inteiro fica num arquivo só, estoque.cpp, que cresce a cada etapa.

Etapa 1 · O produto e o map

Cada produto tem nome, preço, quantidade em estoque e um mínimo: a quantidade abaixo da qual a Ana precisa comprar mais. Quatro informações que andam juntas: uma struct.

E onde guardar os produtos? Num std::vector, achar o "caderno" exigiria olhar um por um. Num std::map (mapa, "dicionário"), cada produto fica guardado debaixo de uma chave, o nome, e o map acha a chave rapidamente. De quebra, ele mantém as chaves em ordem alfabética.

#include <format>
#include <iostream>
#include <map>
#include <string>

struct Produto {
    std::string nome;
    double preco = 0.0;
    int quantidade = 0;
    int minimo = 0;            // abaixo disso, repor
};

using Estoque = std::map<std::string, Produto>;

void cadastrar(Estoque& estoque, const Produto& p) {
    estoque[p.nome] = p;
}

void listar(const Estoque& estoque) {
    for (const auto& [nome, p] : estoque) {
        std::cout << std::format("{:<10}{:>5} un.  R$ {:>6.2f}\n", nome, p.quantidade, p.preco);
    }
}

Estoque estoqueInicial() {

    cadastrar(estoque, {"mochila", 89.9, 5, 2});

int main() {

Etapa 2 · Entrada e saída de mercadoria

Chegou mercadoria: entrada, a quantidade sobe. Vendeu: saída, a quantidade desce. As duas precisam de cuidado: o produto tem de existir, a quantidade tem de ser positiva e, na saída, não dá para tirar mais do que há. As duas funções novas (o resto do arquivo continua como na etapa 1):

bool entrada(Estoque& estoque, const std::string& nome, int qtd) {
    auto it = estoque.find(nome);
    if (it == estoque.end()) {
        std::cout << "Produto não encontrado: " << nome << '\n';
        return false;
    }
    if (qtd <= 0) {
        std::cout << "Quantidade inválida: " << qtd << '\n';
        return false;
    }
    it->second.quantidade += qtd;
    return true;
}

bool saida(Estoque& estoque, const std::string& nome, int qtd) {
    auto it = estoque.find(nome);
    if (it == estoque.end()) {
        std::cout << "Produto não encontrado: " << nome << '\n';
        return false;
    }
    Produto& p = it->second;
    if (qtd <= 0 || qtd > p.quantidade) {
        std::cout << std::format("Quantidade inválida para {}: pedido {}, há {}\n",
                                 nome, qtd, p.quantidade);
        return false;
    }
    p.quantidade -= qtd;
    return true;
}
TrechoO que faz
auto it = estoque.find(nome);Procura a chave. Devolve um iterador: uma "seta" apontando para o item achado.
it == estoque.end()Se não achou, a seta aponta para end(), "depois do último". É assim que se pergunta "não existe?".
it->secondO item é um par: it->first é a chave (o nome), it->second é o Produto guardado no map.
Produto& p = it->second;Um apelido (referência) para o produto dentro do map: mexer em p é mexer no estoque. Sem o &, seria uma cópia, e a saída não mudaria nada.
return false;Recusa e avisa quem chamou. A mensagem com o motivo já foi mostrada.

Etapa 3 · Buscar com std::optional

Agora a Ana quer consultar um produto: "tem mochila? quanto custa?". Uma função buscar que devolve o Produto… mas e se não existir? Devolver um produto vazio confundiria (um produto com preço zero existe ou não?). Para isso existe o std::optional C++17: uma caixinha que tem um produto ou nada.

std::optional<Produto> buscar(const Estoque& estoque, const std::string& nome) {
    auto it = estoque.find(nome);
    if (it == estoque.end()) {
        return std::nullopt;
    }
    return it->second;
}

Junto com #include <optional> no topo. E o main, com três jeitos de usar o resultado:

int main() {
    Estoque estoque = estoqueInicial();

    std::optional<Produto> p = buscar(estoque, "mochila");
    if (p.has_value()) {
        std::cout << p->nome << ": " << p->quantidade << " un. a R$ " << p->preco << '\n';
    }

    auto q = buscar(estoque, "glitter");
    if (!q) {
        std::cout << "Não temos glitter.\n";

        std::cout << "cola: " << r->quantidade << " un.\n";

}

Etapa 5 · Relatório ordenado por valor

"Onde está o meu dinheiro?" O valor em estoque de um produto é preço × quantidade. A Ana quer uma tabela do que vale mais para o que vale menos, com o total no fim. O map está em ordem de nome, e não dá para reordená-lo: a ordem do map é sempre a das chaves. Então copiamos os produtos para um std::vector e ordenamos o vetor com std::sort, dizendo o critério com uma lambda.

O Produto ganha um método que calcula o valor, e entra a função relatorio (mais #include <algorithm> e #include <vector>):

struct Produto {
    std::string nome;
    double preco = 0.0;
    int quantidade = 0;
    int minimo = 0;            // abaixo disso, repor

    double valor() const { return preco * quantidade; }
};

void relatorio(const Estoque& estoque) {
    std::vector<Produto> lista;
    for (const auto& [nome, p] : estoque) {
        lista.push_back(p);
    }
    std::sort(lista.begin(), lista.end(), [](const Produto& a, const Produto& b) {
        return a.valor() > b.valor();
    });

    std::cout << std::format("{:<10}{:>5}{:>9}{:>10}\n", "Produto", "Qtd", "Preço", "Valor");
    double total = 0.0;
    for (const auto& p : lista) {
        std::cout << std::format("{:<10}{:>5}{:>9.2f}{:>10.2f}\n",
                                 p.nome, p.quantidade, p.preco, p.valor());
        total += p.valor();
    }
    std::cout << std::format("{:<24}{:>10.2f}\n", "Total", total);
}

            } else {

#include <algorithm>
#include <format>
#include <fstream>
#include <iostream>
#include <map>
#include <optional>
#include <sstream>
#include <string>
#include <vector>

struct Produto {
    std::string nome;
    double preco = 0.0;
    int quantidade = 0;
    int minimo = 0;            // abaixo disso, repor

    double valor() const { return preco * quantidade; }
};

using Estoque = std::map<std::string, Produto>;

void cadastrar(Estoque& estoque, const Produto& p) {
    estoque[p.nome] = p;
}

void listar(const Estoque& estoque) {
    for (const auto& [nome, p] : estoque) {
        std::cout << std::format("{:<10}{:>5} un.  R$ {:>6.2f}\n", nome, p.quantidade, p.preco);
    }
}

bool entrada(Estoque& estoque, const std::string& nome, int qtd) {
    auto it = estoque.find(nome);
    if (it == estoque.end()) {
        std::cout << "Produto não encontrado: " << nome << '\n';
        return false;
    }
    if (qtd <= 0) {
        std::cout << "Quantidade inválida: " << qtd << '\n';
        return false;
    }
    it->second.quantidade += qtd;
    return true;
}

bool saida(Estoque& estoque, const std::string& nome, int qtd) {
    auto it = estoque.find(nome);
    if (it == estoque.end()) {
        std::cout << "Produto não encontrado: " << nome << '\n';
        return false;
    }
    Produto& p = it->second;
    if (qtd <= 0 || qtd > p.quantidade) {
        std::cout << std::format("Quantidade inválida para {}: pedido {}, há {}\n",
                                 nome, qtd, p.quantidade);
        return false;
    }
    p.quantidade -= qtd;
    if (p.quantidade <= p.minimo) {
        std::cout << std::format("ALERTA: {} ficou com {} (mínimo {})\n",
                                 nome, p.quantidade, p.minimo);
    }
    return true;
}

std::optional<Produto> buscar(const Estoque& estoque, const std::string& nome) {
    auto it = estoque.find(nome);
    if (it == estoque.end()) {
        return std::nullopt;
    }
    return it->second;
}

void alertas(const Estoque& estoque) {
    int contador = 0;
    for (const auto& [nome, p] : estoque) {
        if (p.quantidade <= p.minimo) {
            std::cout << std::format("Repor {}: {} no estoque, mínimo {}\n",
                                     nome, p.quantidade, p.minimo);
            ++contador;
        }
    }
    if (contador == 0) {
        std::cout << "Nenhum produto abaixo do mínimo.\n";
    }
}

void relatorio(const Estoque& estoque) {
    std::vector<Produto> lista;
    for (const auto& [nome, p] : estoque) {
        lista.push_back(p);
    }
    std::sort(lista.begin(), lista.end(), [](const Produto& a, const Produto& b) {
        return a.valor() > b.valor();
    });

    std::cout << std::format("{:<10}{:>5}{:>9}{:>10}\n", "Produto", "Qtd", "Preço", "Valor");
    double total = 0.0;
    for (const auto& p : lista) {
        std::cout << std::format("{:<10}{:>5}{:>9.2f}{:>10.2f}\n",
                                 p.nome, p.quantidade, p.preco, p.valor());
        total += p.valor();
    }
    std::cout << std::format("{:<24}{:>10.2f}\n", "Total", total);
}

void salvar(const Estoque& estoque, const std::string& arquivo) {
    std::ofstream arq{arquivo};
    for (const auto& [nome, p] : estoque) {
        arq << nome << ',' << p.preco << ',' << p.quantidade << ',' << p.minimo << '\n';
    }
}

Estoque carregar(const std::string& arquivo) {
    Estoque estoque;
    std::ifstream arq{arquivo};
    std::string linha;
    int numero = 0;
    while (std::getline(arq, linha)) {
        ++numero;
        std::istringstream campos{linha};
        std::string nome, preco, qtd, minimo;
        std::getline(campos, nome, ',');
        std::getline(campos, preco, ',');
        std::getline(campos, qtd, ',');
        std::getline(campos, minimo);
        try {
            cadastrar(estoque, {nome, std::stod(preco), std::stoi(qtd), std::stoi(minimo)});
        } catch (const std::exception&) {
            std::cout << "Linha " << numero << " ignorada: " << linha << '\n';
        }
    }
    return estoque;
}

Resumo

  • std::map<std::string, Produto> guarda pela chave e percorre em ordem alfabética; for (const auto& [nome, p] : estoque) separa chave e valor.
  • Para procurar, find e compare com end(). O [] cria a chave que não existe: um erro de digitação vira produto novo.
  • Produto& p = it->second; mexe no produto dentro do map; sem &, numa cópia.
  • std::optional<Produto> = "um produto ou nada". Devolva std::nullopt quando não achar; teste com if (auto p = buscar(…)). .value() numa caixa vazia lança std::bad_optional_access.
  • Para ordenar por outro critério, copie para um std::vector e use std::sort(início, fim, lambda); a lambda responde "a vem antes de b?".
  • CSV: std::ofstream + << para gravar; std::ifstream + getline(campos, x, ',') + stoi/stod para ler. Capture a exceção de conversão por linha, senão uma linha ruim derruba o programa.
