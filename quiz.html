Como os trechos funcionam

Para economizar espaço, os trechos que só têm instruções estão, na verdade, dentro de um int main() { … }, com os #include necessários (<iostream>, <string>, <vector>…). Quando o trecho tem funções, structs ou classes, o main aparece. Nas saídas, o cout não pula linha sozinho: std::cout << 1 << 2; mostra 12.

1. O que este código imprime?

std::cout << 7 / 2;
Explicação

Os dois números são int, então a divisão é inteira: o resultado é 3 e a parte decimal é jogada fora (não arredonda).

Explicação

8. O que este código imprime?

std::cout << (10 > 3 && 2 > 5);
Explicação

10 > 3 é verdadeiro, mas 2 > 5 é falso; com &&, o resultado é falso. O cout mostra um bool como 0 ou 1, a menos que você peça std::boolalpha.

Revise: Operadores Lógicos

9. O que este código imprime?

std::cout << std::boolalpha << (3 == 3.0);
Explicação

O 3 é convertido para double antes de comparar, e 3.0 == 3.0. Com std::boolalpha, o cout escreve true/false.

Revise: Booleanos

10. O que este código imprime?

char c = 'A';

std::cout << c;
Explicação

Um char é um número (o código da letra). 'A' + 2 é o código do 'C', e como c é char, o cout mostra a letra.

Revise: Caracteres

11. O que este código imprime?

Explicação

Na conta, o char vira int: 'A' vale 65, e 65 + 1 = 66. O resultado é um int, então aparece o número, não a letra.

Revise: Caracteres

59. O que este código imprime?

struct T {
    T() { std::cout << "C"; }
    ~T() { std::cout << "D"; }

    }
    std::cout << "F";

Explicação

a nasce (C), b nasce (C) e morre na } do bloco (D), aparece o F, e a morre no fim do main (D). O destrutor roda sozinho: é o RAII.

78. O que este código imprime?

std::optional<int> o;
std::cout << o.value_or(7);
Explicação

O optional está vazio, então value_or devolve o valor reserva. (o.value() lançaria std::bad_optional_access.)

79. O que este código imprime?

auto [a, b] = std::pair{3, "três"};
std::cout << b << a;
Explicação

A desestruturação abre o par em duas variáveis: a = 3 e b = "três". O código mostra b primeiro.

Missão: o código da pergunta sobre maior(3, 7.5) não compila. Sem mudar o template, faça a chamada funcionar e mostrar 7.5, dizendo ao compilador qual tipo usar.

#include <iostream>

template <typename T>
T maior(T a, T b) {
    return a > b ? a : b;
}

int main() {
    std::cout << maior(3, 7.5) << '\n';
}

#include <iostream>

template <typename T>
T maior(T a, T b) {
    return a > b ? a : b;
}

int main() {
    std::cout << maior<double>(3, 7.5) << '\n';
