Projeto Contas Bancárias (POO)

Um banco é o exemplo perfeito de por que a orientação a objetos existe: o saldo de uma conta não pode ser mudado por qualquer um, de qualquer jeito. Neste projeto você vai construir, em oito etapas, um pequeno banco em C++: contas que depositam e sacam com validação, uma exceção própria para "saldo insuficiente", uma conta poupança que rende no fim do mês, uma lista de contas de tipos diferentes, um extrato bem alinhado e, no fim, um programa dividido em três arquivos com um menu que você usa digitando comandos.

Você vai praticar
  • Classes com dados private e métodos public (encapsulamento).
  • Validar valores: primeiro devolvendo bool, depois com exceções e uma classe de exceção própria.
  • Herança e polimorfismo: virtual, override e destrutor virtual.
  • std::vector<std::unique_ptr<Conta>>: uma lista de contas de tipos diferentes (ponteiros inteligentes).
  • Texto alinhado com std::format.
  • Separar o programa em .h e .cpp e compilar vários arquivos.
  • Ler comandos do teclado com getline.

Todos os programas foram compilados e executados na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/cpp/banco, com o g++ 15.2 e o comando padrão do guia, g++ -std=c++23 -Wall -Wextra. Cada etapa tem uma caixa Experimente em que você faz a etapa no navegador.

Etapa 1 · A classe Conta

Uma conta tem duas informações: o titular (o nome do dono) e o saldo. E sabe fazer uma coisa, por enquanto: receber um depósito. Em C++, isso vira uma classe:

#include <string>

public:
    explicit Conta(std::string titular) : titular_{titular} {}

    void depositar(double valor) {
        saldo_ += valor;
    }

    std::string titular() const { return titular_; }
    double saldo() const { return saldo_; }

private:
    std::string titular_;
    double saldo_ = 0.0;

double e dinheiro

O double guarda números em binário, e a maioria dos centavos não tem representação exata em binário (como 1/3 não tem em decimal). Veja:

#include <format>
#include <iostream>

int main() {
    double total = 0.1 + 0.2;
    std::cout << total << '\n';
    std::cout << std::format("{}", total) << '\n';
    std::cout << (total == 0.3) << '\n';
}

$ g++ -std=c++23 -Wall -Wextra frac.cpp -o frac
$ ./frac
0.3
0.30000000000000004
0

O cout arredonda e mostra 0.3, mas o valor guardado é 0.30000000000000004, e por isso total == 0.3 dá falso (0). Para aprender POO, o double serve. Um banco de verdade guarda centavos inteiros (long long, com R$ 10,50 guardado como 1050): fica como desafio no fim da página. Mais em float e double.

Etapa 2 · Validar depósito e saque

A conta da etapa 1 aceita ana.depositar(-500), e isso é, na prática, um saque escondido. Também falta o saque. As regras do banco:

  • depósito e saque só com valor positivo;
  • saque só se houver saldo.

Primeira forma de fazer: cada método devolve bool (true = deu certo, false = recusado) e não mexe no saldo quando recusa.

#include <iostream>
#include <string>

class Conta {
public:
    explicit Conta(std::string titular) : titular_{titular} {}

    bool depositar(double valor) {
        if (valor <= 0) {
            return false;          // recusado: nada muda
        }
        saldo_ += valor;
        return true;
    }

    bool sacar(double valor) {
        if (valor <= 0 || valor > saldo_) {
            return false;
        }
        saldo_ -= valor;
        return true;
    }

    std::string titular() const { return titular_; }
    double saldo() const { return saldo_; }

private:
    std::string titular_;
    double saldo_ = 0.0;
};

int main() {
    Conta ana{"Ana"};
    ana.depositar(1000.0);

    if (ana.sacar(250.0)) {
        std::cout << "Saque de 250 feito.\n";
    }
    if (!ana.sacar(5000.0)) {
        std::cout << "Saque de 5000 recusado.\n";
    }
    if (!ana.depositar(-50.0)) {
        std::cout << "Depósito de -50 recusado.\n";
    }
    ana.sacar(800.0);      // ninguém conferiu se deu certo...
    std::cout << ana.titular() << " tem R$ " << ana.saldo() << '\n';
}

Etapa 3 · A exceção SaldoInsuficiente

Uma exceção é um aviso de "deu errado" que não pode ser ignorado: quando um método faz throw (lança), o programa para o que estava fazendo e pula para o catch (captura) mais próximo. Se não houver nenhum, o programa termina.

Para o saque sem saldo, vamos criar a nossa própria exceção, SaldoInsuficiente. Para valor zero ou negativo, usamos uma que já vem pronta na biblioteca: std::invalid_argument ("argumento inválido").

#include <format>
#include <iostream>
#include <stdexcept>
#include <string>

class SaldoInsuficiente : public std::runtime_error {
public:
    SaldoInsuficiente(double saldo, double pedido)
        : std::runtime_error{std::format("saldo insuficiente (saldo {:.2f}, pedido {:.2f})",
                                         saldo, pedido)} {}
};

class Conta {
public:
    explicit Conta(std::string titular) : titular_{titular} {}

    void depositar(double valor) {
        if (valor <= 0) {
            throw std::invalid_argument{"o valor precisa ser positivo"};
        }
        saldo_ += valor;
    }

    void sacar(double valor) {
        if (valor <= 0) {
            throw std::invalid_argument{"o valor precisa ser positivo"};
        }
        if (valor > saldo_) {
            throw SaldoInsuficiente{saldo_, valor};
        }
        saldo_ -= valor;
    }

    std::string titular() const { return titular_; }
    double saldo() const { return saldo_; }

private:
    std::string titular_;
    double saldo_ = 0.0;
};

int main() {
    Conta ana{"Ana"};
    ana.depositar(1000.0);

    try {
        ana.sacar(250.0);
        std::cout << "Saque de 250 feito.\n";
        ana.sacar(5000.0);
        std::cout << "Esta linha não aparece.\n";
    } catch (const SaldoInsuficiente& e) {
        std::cout << "Recusado: " << e.what() << '\n';
    }

    try {
        ana.depositar(-50.0);
    } catch (const std::invalid_argument& e) {
        std::cout << "Erro: " << e.what() << '\n';
    }

    std::cout << ana.titular() << " tem R$ " << ana.saldo() << '\n';
}

Quando dá errado: uma exceção que ninguém captura

Coloque ana.sacar(800.0); fora de qualquer try, logo antes da última linha do main:

  what():  saldo insuficiente (saldo 750.00, pedido 800.00)
Abortado                   (imagem do núcleo gravada) ./banco

134
  • terminate called after throwing an instance of 'SaldoInsuficiente': "terminar, chamado depois de lançar um SaldoInsuficiente". Como ninguém capturou, o C++ chama std::terminate, que encerra o programa.
  • what(): mostra a nossa mensagem. Ainda bem que ela diz o saldo e o pedido.
  • Abortado (imagem do núcleo gravada) é o Bash avisando que o programa foi abortado; o código de saída 134 é 128 + 6, o número do sinal de "abortar".
  • A frase final Ana tem R$ 750 nunca foi impressa. Diferente do bool esquecido, o erro não passou despercebido.

Como consertar: toda operação que pode lançar fica dentro de um try com o catch certo, como as outras do main.

Etapa 4 · A conta poupança

A poupança é uma conta com tudo o que a conta comum tem (titular, saldo, depósito, saque) e uma diferença: no fim do mês, ela rende juros. Em vez de copiar a classe inteira, dizemos que ContaPoupanca herda de Conta (herança) e escrevemos só o que muda.

Para o "fim do mês" funcionar com qualquer conta, a classe base ganha dois métodos virtual: tipo() (o nome do tipo de conta) e fecharMes(). virtual quer dizer "uma classe filha pode trocar este método pelo dela, e o C++ vai chamar o da filha mesmo quando só souber que tem uma Conta nas mãos". Isso é o polimorfismo.

Os #include, a SaldoInsuficiente, o depositar e o sacar continuam iguais à etapa 3. O resto do banco.cpp fica assim (o arquivo inteiro está na missão desta etapa):

Um banco tem muitas contas, de tipos misturados. O natural seria um std::vector<Conta>. Veja o que acontece:

    contas.push_back(Conta{"Ana"});
    contas.push_back(ContaPoupanca{"Bruno", 0.005});

        conta.depositar(1000.0);
        conta.fecharMes();

    }

$ g++ -std=c++23 -Wall -Wextra banco.cpp -o banco
$ ./banco
Ana (Corrente): R$ 1000

Compilou sem aviso e o Bruno virou "Corrente" e não rendeu. Cada lugar de um vector<Conta> tem o tamanho exato de uma Conta. Ao guardar a poupança ali, o C++ copia só a parte Conta e joga fora o resto (a taxa e o "jeito poupança" de ser). Isso tem nome: fatiamento (slicing).

A solução é guardar no vetor não as contas, mas ponteiros para elas: todo ponteiro tem o mesmo tamanho, aponte ele para uma conta comum ou para uma poupança. E, para não ter de lembrar de apagar cada conta com delete, usamos o ponteiro inteligente std::unique_ptr (ponteiros inteligentes): quando o vetor some, ele apaga as contas sozinho. As classes ficam iguais à etapa 4; acrescente #include <memory> e #include <vector> no topo e troque o main:

Etapa 6 · O extrato com std::format

Um banco precisa lembrar cada movimento, não só o saldo. Cada movimento tem uma descrição ("Depósito", "Saque", "Rendimento") e um valor: positivo quando entra, negativo quando sai. Isso é uma struct, e a conta guarda um std::vector delas. Para mostrar o extrato em colunas alinhadas, usamos std::format.

#include <format>
#include <iostream>
#include <memory>
#include <stdexcept>
#include <string>
#include <vector>

class SaldoInsuficiente : public std::runtime_error {
public:
    SaldoInsuficiente(double saldo, double pedido)
        : std::runtime_error{std::format("saldo insuficiente (saldo {:.2f}, pedido {:.2f})",
                                         saldo, pedido)} {}
};

struct Movimento {
    std::string descricao;
    double valor;              // positivo entra, negativo sai
};

class Conta {
public:
    explicit Conta(std::string titular) : titular_{titular} {}
    virtual ~Conta() = default;

    virtual std::string tipo() const { return "Corrente"; }
    virtual void fecharMes() {}      // a conta corrente não rende

    void depositar(double valor, std::string descricao = "Depósito") {
        if (valor <= 0) {
            throw std::invalid_argument{"o valor precisa ser positivo"};
        }
        saldo_ += valor;
        movimentos_.push_back({descricao, valor});
    }

    void sacar(double valor) {
        if (valor <= 0) {
            throw std::invalid_argument{"o valor precisa ser positivo"};
        }
        if (valor > saldo_) {
            throw SaldoInsuficiente{saldo_, valor};
        }
        saldo_ -= valor;
        movimentos_.push_back({"Saque", -valor});
    }

    std::string extrato() const {
        std::string texto = std::format("Extrato de {} ({})\n", titular_, tipo());
        for (const auto& m : movimentos_) {
            texto += std::format("  {:<12}{:>+10.2f}\n", m.descricao, m.valor);
        }
        texto += std::format("  {:<12}{:>10.2f}\n", "Saldo", saldo_);
        return texto;
    }

    std::string titular() const { return titular_; }
    double saldo() const { return saldo_; }

private:
    std::string titular_;
    double saldo_ = 0.0;
    std::vector<Movimento> movimentos_;
};

class ContaPoupanca : public Conta {
public:
    ContaPoupanca(std::string titular, double taxa)
        : Conta{titular}, taxa_{taxa} {}

    std::string tipo() const override { return "Poupança"; }

    void fecharMes() override {
        double rendimento = saldo() * taxa_;
        if (rendimento > 0) {
            depositar(rendimento, "Rendimento");
        }
    }

private:
    double taxa_;
};

int main() {

Resumo

  • Dados private + métodos public: o saldo só muda por depositar e sacar, e o compilador barra ana.saldo_ = ….
  • Validar com bool funciona, mas a resposta pode ser ignorada ([[nodiscard]] só avisa). Uma exceção não passa despercebida: sem catch, o programa termina com terminate called after throwing….
  • Exceção própria: class SaldoInsuficiente : public std::runtime_error, com a mensagem montada no construtor e lida com what(). Capture com catch (const Tipo& e), do mais específico para o mais geral.
  • Herança: class ContaPoupanca : public Conta. Na mãe, virtual (e destrutor virtual); na filha, override. Sem virtual, a função errada é chamada em silêncio.
  • Contas de tipos diferentes num vetor: std::vector<std::unique_ptr<Conta>> com std::make_unique. Um vector<Conta> fatia a poupança; unique_ptr não se copia, então percorra com auto&.
  • std::format("{:<12}{:>+10.2f}", …) alinha colunas, fixa as casas decimais e mostra o sinal.
  • .h com as declarações e #pragma once, .cpp com os corpos (Conta::metodo); compile todos os .cpp juntos, senão vem referência não definida do ligador.
