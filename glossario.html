C++ Glossário

Os termos que aparecem no guia, em ordem alfabética, explicados em uma ou duas frases, cada um com o link para a aula em que é explicado com calma. Termos em inglês aparecem com a tradução; quando o nome em inglês é o mais usado no dia a dia (como template ou lambda), ele é a entrada principal.

Dica

Use Ctrl+F no navegador para achar um termo, ou o índice de letras abaixo. Para consultas rápidas, veja também as referências de tipos, de std::string, de containers, de algoritmos e de mensagens de erro.

A · B · C · D · E · F · G · H · I · L · M · N · O · P · R · S · T · U · V · W

A

Algoritmo
Uma receita passo a passo para resolver um problema. Na biblioteca padrão, são as funções prontas de <algorithm> que ordenam, procuram, contam e transformam coleções: std::sort, std::find, std::count_if… Veja: Algoritmos e Referência de Algoritmos.
Alocação dinâmica
Pedir memória enquanto o programa roda (no heap), em vez de declarar uma variável comum. É o que new, std::vector e std::make_unique fazem. Veja: Memória Dinâmica.
Argumento
O valor que você entrega a uma função quando a chama: em soma(2, 3), os argumentos são 2 e 3. Do lado de dentro, eles chegam nos parâmetros. Veja: Parâmetros e Argumentos.
Array (vetor fixo)
Uma fileira de variáveis do mesmo tipo, lado a lado na memória, com tamanho fixo: int notas[3];. O array "cru" do C não sabe o próprio tamanho e não confere índices; prefira std::array ou std::vector. Veja: Arrays e std::array.
Atribuição
Guardar um valor numa variável que já existe, com =: idade = 31;. Os atalhos +=, -=, *= fazem a conta e guardam. Veja: Operadores de Atribuição.
auto C++11
Palavra que pede ao compilador para descobrir o tipo sozinho, olhando o valor: auto total = 10.5; vira double. Veja: auto.
Aviso (warning)
Mensagem do compilador sobre algo suspeito que não impede o programa de ser criado, como uma variável não usada. Quase sempre aponta um defeito real; ligue-os com -Wall -Wextra. Veja: Avisos.

B

Biblioteca
Código pronto, escrito por outras pessoas, que o seu programa usa. Pode ser só de cabeçalhos (header-only) ou vir compilada, e então precisa ser ligada (-lnome). Veja: Usar Bibliotecas Externas.
Biblioteca padrão (standard library)
A biblioteca que vem com todo compilador C++ e faz parte do padrão ISO: std::cout, std::string, std::vector, os algoritmos, std::thread… Tudo nela mora no namespace std. Veja: O que é a STL.
Bloco
Um trecho de código entre chaves { }. As variáveis criadas dentro de um bloco só existem até a } que o fecha. Veja: Escopo.
bool
O tipo que só guarda true (verdadeiro) ou false (falso). É o resultado das comparações. Veja: Booleanos.
break
Sai do laço (for, while) ou do switch na hora. Veja: break e continue.

C

Cabeçalho (header)
Arquivo com declarações que outros arquivos incluem com #include. Os da biblioteca padrão não têm extensão (<iostream>, <vector>); os seus costumam terminar em .h ou .hpp. Veja: Arquivos .h e .cpp.
char (caractere)
O tipo de um caractere, escrito entre aspas simples: 'A'. Por dentro, é um número pequeno (o código da letra). Letras acentuadas em UTF-8 ocupam mais de um char. Veja: Caracteres e Acentos e UTF-8.
Classe
A "planta" de um tipo novo, que junta dados (atributos) e ações (métodos): class Conta { … };. A partir dela, você cria objetos. Veja: Classes e Objetos.
Classe abstrata
Classe com pelo menos um método virtual puro (= 0), que serve só de modelo: não dá para criar objetos dela, só das classes filhas. Veja: Classes Abstratas.
CMake
Ferramenta que descreve como montar um projeto (arquivo CMakeLists.txt) e gera os arquivos de construção para o make, o Ninja ou uma IDE. É o padrão de fato dos projetos C++. Veja: CMake.
Código de saída (exit code)
O número que o programa devolve ao terminar: 0 = sucesso. É o valor do return do main, visto com echo $?. Quando o sistema mata o programa, é 128 + o número do sinal (139 = Segmentation fault). Veja: Códigos de saída.
Código-fonte
O texto que você escreve (ola.cpp), que pessoas leem e o compilador traduz. Veja: Como o C++ Vira Programa.
Comentário
Texto que o compilador ignora, escrito para pessoas: // até o fim da linha ou /* em bloco */. Veja: Comentários.
Compilador
O programa que traduz o código-fonte C++ para código de máquina. Os principais são o g++ (do GCC), o clang++ (do LLVM, usado no editor do guia) e o MSVC (da Microsoft). Veja: Como o C++ Vira Programa e Compilar com g++.
Compilação
A etapa em que cada arquivo .cpp é traduzido para um arquivo-objeto (.o). Erros dessa etapa têm arquivo, linha e coluna. Veja: Lendo Erros do Compilador.
Comportamento indefinido (undefined behavior, UB)
O que acontece quando o programa faz algo que o padrão proíbe, como ler fora de um array, usar uma variável sem valor ou estourar um int. O compilador não é obrigado a avisar e o resultado pode ser qualquer coisa: funcionar, mostrar lixo ou travar. Veja: Comportamento Indefinido.
Concept (conceito) C++20
Uma exigência com nome para os tipos de um template: template <std::integral T> só aceita inteiros. Deixa as mensagens de erro muito mais claras. Veja: Concepts.
const
Marca algo como "não pode mudar": const int maximo = 10;. Num método, const promete não alterar o objeto. Veja: Constantes, const com Ponteiros e Métodos const.
constexpr C++11 e consteval C++20
constexpr permite calcular um valor durante a compilação; consteval obriga isso. O resultado já entra pronto no programa. Veja: constexpr e consteval.
Construtor
Método especial, com o mesmo nome da classe, que roda quando um objeto nasce e deixa-o pronto para uso: Conta(std::string dono). Veja: Construtores.
Container (recipiente)
Um tipo da biblioteca padrão que guarda vários valores: std::vector, std::list, std::map, std::set… Cada um organiza os itens de um jeito. Veja: O que é a STL e Referência de Containers.
continue
Pula o resto desta volta do laço e vai para a próxima. Veja: break e continue.
Conversão de tipos (cast)
Transformar um valor de um tipo em outro. Algumas são automáticas (int → double); as explícitas usam static_cast<int>(3.7). Veja: Conversão de Tipos.
Cópia
Criar um objeto novo, independente, com o mesmo conteúdo de outro. Em C++, passar por valor e atribuir copiam. Veja: Cópia e Movimento.

D

Declaração
Apresenta um nome ao compilador e diz o seu tipo: int soma(int a, int b); diz que a função existe, sem dizer o que ela faz. Veja: Funções e Arquivos .h e .cpp.
Definição
A declaração completa, com o corpo (int soma(int a, int b) { return a + b; }) ou com a memória (int total = 0;). Cada coisa pode ser declarada várias vezes, mas definida uma vez só no programa. Veja: Compilar Vários Arquivos.
delete
Devolve a memória pedida com new (delete[] para arrays). Esquecer gera vazamento; repetir gera double free. Prefira ponteiros inteligentes. Veja: new e delete.
Depurador (debugger)
Programa que roda o seu passo a passo, mostrando os valores das variáveis. No Linux, o gdb. Veja: Depurar com o GDB.
deque
"Fila de duas pontas": container que cresce rápido pelo começo e pelo fim. Veja: list e deque.
Desestruturação (structured bindings) C++17
Abrir um par, tupla ou struct em várias variáveis de uma vez: auto [nome, nota] = par;. Veja: pair, tuple e Desestruturação.
Destrutor
Método especial (~Conta()) que roda sozinho quando o objeto deixa de existir, para liberar o que ele usava. É a base do RAII. Veja: Destrutores e RAII.
double
O tipo padrão para números com casas decimais (ponto flutuante de precisão dupla, cerca de 15 algarismos). Veja: float e double.

E

Encapsulamento
Esconder os dados de um objeto (private) e só deixar mexer neles por métodos (public), que garantem que o objeto fique sempre válido. Veja: public e private.
enum class (enumeração) C++11
Um tipo com uma lista fechada de valores com nome: enum class Cor { Vermelho, Verde };, usados como Cor::Verde. Veja: Enums.
Entrada padrão (stdin)
De onde o programa lê: normalmente o teclado. Em C++, std::cin e std::getline. Veja: Entrada com cin.
Escopo
A região do código em que um nome existe. Uma variável criada dentro de um bloco { } some na }. Veja: Escopo.
Exceção
Um jeito de avisar um erro "pulando" para quem sabe tratá-lo: throw lança, try/catch captura. Se ninguém captura, o programa aborta com terminate called after throwing…. Veja: Exceções.
Executável
O arquivo final, que o sistema roda: ./ola. É o resultado da compilação e da ligação. Veja: Olá, Mundo.
Expressão
Um pedaço de código que produz um valor: preco * 2, x > 0, soma(2, 3). Veja: Operadores Aritméticos.

F

float
Número com casas decimais de precisão simples (cerca de 7 algarismos). Use double, a menos que tenha um bom motivo. Veja: float e double.
for
Laço com contador: for (int i = 0; i < 5; i++). Veja: for.
for de intervalo (range-for) C++11
Laço que passa por todos os itens de uma coleção, sem índice: for (int n : notas). Veja: for de Intervalo.
friend (amigo)
Dá a uma função ou classe de fora acesso aos membros privados de uma classe. Use com moderação. Veja: friend.
Função
Um bloco de código com nome, que recebe parâmetros e pode devolver um valor: int dobro(int x) { return 2 * x; }. Veja: Funções.
Função membro
O nome oficial do método: uma função que pertence a uma classe. Veja: Métodos.

G

g++ / GCC
O compilador C++ do projeto GNU (GCC = GNU Compiler Collection), o mais comum no Linux. O guia usa o g++ 15. Veja: Compilar com g++ e Instalar no Linux.
gdb
O depurador do projeto GNU. Veja: Depurar com o GDB.
getline
Lê uma linha inteira, com espaços, para uma std::string: std::getline(std::cin, nome);. Veja: Ler uma Linha.

H

Heap (monte, memória livre)
A grande área de memória de onde vêm os pedidos feitos durante a execução (new, std::vector, std::string). É maior que a pilha, mas alguém precisa devolver a memória (de preferência, um destrutor). Veja: Como a Memória Funciona.
Herança
Criar uma classe a partir de outra, aproveitando o que ela tem: class Gato : public Animal. A filha "é um" tipo da mãe. Veja: Herança.

I

IDE (ambiente de desenvolvimento integrado)
Um editor que junta escrever, compilar e depurar: VS Code, CLion, Visual Studio, Qt Creator. Veja: Editores e IDEs.
Identificador
O nome que você dá a uma variável, função ou classe. Começa com letra ou _, sem espaços, e maiúsculas contam. Veja: Nomes de Variáveis.
if / else
Decisão: executa um bloco se a condição for verdadeira e, opcionalmente, outro se for falsa. Veja: if e else.
#include
Instrução do pré-processador que cola o conteúdo de um cabeçalho no lugar dela. Veja: O Pré-processador.
Inicialização
Dar o primeiro valor a uma variável, na hora em que ela é criada: int x = 0; ou int x{0};. As chaves recusam conversões que perdem informação. Variáveis sem inicialização guardam lixo. Veja: Variáveis.
inline
Permite que uma função ou variável C++17 seja definida num cabeçalho incluído por vários .cpp, sem dar multiple definition. Veja: Arquivos .h e .cpp.
int
O tipo inteiro padrão; no Linux de 64 bits, vai de −2.147.483.648 a 2.147.483.647. Veja: Inteiros e Tipos e Limites.
Instância
Outro nome para objeto: um exemplar criado a partir de uma classe. Veja: Classes e Objetos.
Iterador
Um "marcador de posição" que anda pelos itens de um container: v.begin() aponta o primeiro, v.end() um depois do último, *it lê o item e ++it avança. É a ponte entre containers e algoritmos. Veja: Iteradores.

L

Lambda C++11
Uma função sem nome, escrita no meio do código: [](int x) { return x > 5; }. Os colchetes dizem quais variáveis de fora ela "captura". Muito usada com algoritmos. Veja: Lambdas.
Laço (loop)
Repetição: while, do-while, for e o for de intervalo. Veja: while e for.
Ligador (linker)
O programa (ld, no Linux) que junta os arquivos-objeto e as bibliotecas num executável, conferindo se toda função usada foi definida em algum lugar. Seus erros: undefined reference, multiple definition. Veja: Como o C++ Vira Programa e Erros de ligação.
Ligação (linking)
A etapa feita pelo ligador, depois da compilação. Veja: Compilar Vários Arquivos.
list
Lista duplamente encadeada: cada item aponta o vizinho. Inserir no meio é rápido, mas não há acesso direto por índice (e std::sort não funciona nela; use l.sort()). Veja: list e deque.
Literal
Um valor escrito direto no código: 42, 3.14, 'A', "Ana", true. Veja: Tipos de Dados.
lvalue / rvalue
Termos que aparecem nas mensagens de erro. Um lvalue é algo com endereço, que pode ficar do lado esquerdo do = (uma variável); um rvalue é um valor temporário (5, x + 1). Veja: Referências e Semântica de Movimento.

M

main
A função por onde todo programa C++ começa: int main() { … }. O valor que ela devolve é o código de saída. Veja: Olá, Mundo.
make / Makefile
Ferramenta que recompila só o que mudou, seguindo as regras de um arquivo Makefile. Veja: Make.
map
Container de pares chave → valor, mantidos em ordem de chave: std::map<std::string, int> estoque;. Veja: std::map.
Membro
Tudo o que pertence a uma classe ou struct: atributos (dados) e métodos (funções). Acessados com . (ou -> por um ponteiro). Veja: Classes e Objetos.
Membro static
Atributo ou método que pertence à classe, não a cada objeto: um contador de quantas contas foram criadas, por exemplo. Veja: Membros static.
Método
Uma função que pertence a uma classe e age sobre um objeto: conta.depositar(50);. Veja: Métodos.
Módulo C++20
A alternativa moderna aos cabeçalhos: o código é exportado com export module e usado com import. O C++23 trouxe import std; para a biblioteca padrão inteira. Veja: Módulos.
Move (movimento) C++11
Transferir o conteúdo de um objeto para outro sem copiar, "roubando" a memória dele: auto b = std::move(a);. Depois disso, a fica vazio, mas válido. Veja: Semântica de Movimento e Cópia e Movimento.

N

Namespace (espaço de nomes)
Um "sobrenome" para agrupar nomes e evitar conflitos: std::cout é o cout do namespace std. Veja: Namespaces.
new
Pede memória no heap e cria um objeto lá, devolvendo um ponteiro: int* p = new int(5);. Cada new precisa de um delete. Em código moderno, use std::make_unique. Veja: new e delete.
nullptr C++11
O valor de um ponteiro que não aponta para nada. Usar * num nullptr derruba o programa (Segmentation fault). Substitui o antigo NULL. Veja: nullptr.

O

Objeto
Um "exemplar" de uma classe, com os seus próprios dados: Conta minha{"Ana"};. No padrão C++, qualquer região de memória com tipo (até um int) também é chamada de objeto. Veja: Classes e Objetos.
Operador
Um símbolo que faz uma operação: +, ==, &&, <<. A precedência decide quem é calculado primeiro. Veja: Operadores e Precedência.
optional C++17
Uma caixa que pode ter um valor ou estar vazia: std::optional<int>. Bom para funções que às vezes não têm resposta. Veja: optional e variant.
override C++11
Marca, na classe filha, que um método substitui um método virtual da mãe. Se a assinatura não bater, o compilador acusa erro. Veja: Polimorfismo.

P

Padrão ISO (standard)
O documento oficial que define o C++, mantido por um comitê internacional (ISO/IEC 14882). Cada versão tem o ano: C++98, C++03, C++11, C++14, C++17, C++20, C++23 e C++26. Os compiladores implementam o padrão; com o g++, você escolhe a versão com -std=c++23. Veja: Versões do C++ e Novidades.
pair / tuple
std::pair junta dois valores (first, second); std::tuple, quantos você quiser. Veja: pair e tuple.
Parâmetro
A variável, na definição da função, que recebe o argumento: em int dobro(int x), x é o parâmetro. Veja: Parâmetros e Argumentos.
Passagem por referência / por valor
Por valor (int x), a função recebe uma cópia; por referência (int& x), recebe a própria variável e pode mudá-la. const T& evita a cópia sem permitir mudança. Veja: Por Valor × Por Referência.
Pilha (stack, memória)
A área de memória das variáveis locais e das chamadas de função. É rápida e se arruma sozinha: cada variável some quando a função termina. É pequena (no Linux, uns 8 MB); uma recursão sem fim a estoura. Veja: Como a Memória Funciona.
Pilha e fila (std::stack, std::queue)
Containers adaptadores: na pilha, o último a entrar é o primeiro a sair; na fila, o primeiro a entrar é o primeiro a sair. Veja: stack e queue.
POO (Programação Orientada a Objetos)
Um jeito de organizar o programa em objetos que juntam dados e comportamento, com encapsulamento, herança e polimorfismo. Veja: O que é POO.
Polimorfismo
"Muitas formas": chamar o mesmo método (animal.som()) e cada tipo de objeto responder do seu jeito. Em C++, funciona com métodos virtual chamados por referência ou ponteiro para a classe mãe. Veja: Polimorfismo.
Ponteiro
Uma variável que guarda um endereço de memória: int* p = &x;. *p lê o que está naquele endereço. Poderoso e perigoso; prefira referências e ponteiros inteligentes. Veja: Ponteiros.
Ponteiro inteligente (smart pointer) C++11
Um objeto que se comporta como ponteiro e apaga sozinho o que aponta: std::unique_ptr (um dono só) e std::shared_ptr (vários donos, com contagem). Criados com std::make_unique e std::make_shared. Veja: Ponteiros Inteligentes.
Pré-processador
A etapa que roda antes da compilação e trata as linhas com #: #include cola arquivos, #define troca textos, #if liga e desliga trechos. Veja: O Pré-processador.
private / public / protected
Quem pode mexer em cada membro de uma classe: só ela mesma (private), qualquer um (public) ou ela e as filhas (protected). Veja: public e private e Herança.

R

RAII
"Resource Acquisition Is Initialization": a aquisição de um recurso é a inicialização de um objeto. O construtor pega o recurso (memória, arquivo, trava) e o destrutor devolve, automaticamente, mesmo se houver exceção. É a ideia por trás de std::vector, std::fstream e dos ponteiros inteligentes. Veja: Destrutores e RAII.
Range (intervalo) C++20
Qualquer coisa que tenha começo e fim e possa ser percorrida: um vector, uma string, uma view. Os algoritmos std::ranges:: recebem o range inteiro: std::ranges::sort(v). Veja: Ranges.
Recursão
Uma função que chama a si mesma, com um caso de parada. Sem ele, a pilha estoura. Veja: Recursão.
Referência
Um segundo nome para uma variável que já existe: int& r = x;. Mexer em r é mexer em x. Diferente do ponteiro, nunca é nula e não muda de alvo. Veja: Referências.
Retorno
O valor que a função devolve com return; o tipo dele vem antes do nome da função (int, double, ou void para "nada"). Veja: Retorno.

S

Saída padrão (stdout) e saída de erro (stderr)
Para onde o programa escreve: std::cout vai para a saída padrão; std::cerr, para a de erro. As duas aparecem no terminal, mas podem ser separadas (2>). Veja: Saída com cout.
Sanitizer (fiscal)
Verificação que o compilador põe dentro do programa (-fsanitize=address,undefined) para pegar, na linha exata, erros de memória e comportamento indefinido enquanto ele roda. Veja: Sanitizers.
Segmentation fault (falha de segmentação)
Quando o programa acessa memória que não é dele e o sistema o mata (código 139). Causa comum: ponteiro nulo ou inválido. Veja: Mensagens de Erro.
set
Container que guarda valores sem repetição, em ordem. Veja: std::set.
Sinal (signal)
Aviso que o sistema manda a um processo, muitas vezes para matá-lo: SIGSEGV (memória inválida), SIGFPE (divisão por zero), SIGABRT (abortar). Veja: Códigos de saída.
Sobrecarga (overload)
Várias funções com o mesmo nome e parâmetros diferentes; o compilador escolhe a certa pelos argumentos. Também vale para operadores (operator+, operator<<). Veja: Sobrecarga de Funções e Sobrecarga de Operadores.
static
Tem vários sentidos: numa classe, um membro que pertence à classe inteira; numa variável local, uma variável que sobrevive entre chamadas; num arquivo, um nome visível só nele. Veja: Membros static.
std
O namespace da biblioteca padrão. Veja: Namespaces.
STL
"Standard Template Library": o pedaço da biblioteca padrão com os containers, os iteradores e os algoritmos, todos feitos com templates. Veja: O que é a STL.
std::string
O tipo de texto do C++: cresce sozinho, sabe o próprio tamanho e se apaga sozinho. Veja: Strings e Referência de std::string.
string_view C++17
Uma "janela" só de leitura para um texto que já existe, sem copiá-lo. Veja: string_view.
struct
Um tipo que agrupa vários campos: struct Aluno { std::string nome; int nota; };. É igual a uma classe, só que tudo começa public. Veja: Structs.
switch
Escolhe um entre vários case conforme um valor inteiro, char ou enum. Veja: switch.

T

Template (modelo)
Código escrito com tipos "em branco", que o compilador preenche conforme o uso: template <typename T> T maior(T a, T b) serve para int, double, std::string… É assim que std::vector<int> funciona. Veja: Templates de Função e Templates de Classe.
this
Dentro de um método, um ponteiro para o próprio objeto: this->saldo. Veja: this.
Thread (linha de execução)
Um "trabalhador" a mais dentro do mesmo programa, rodando ao mesmo tempo que os outros: std::thread, std::jthread. Veja: Threads.
throw / try / catch
As palavras das exceções: throw lança, try marca o trecho vigiado, catch trata. Veja: Exceções.
Tipo
O que uma variável guarda e quais operações valem para ela: int, double, char, bool, std::string, as suas classes… Em C++, o tipo é decidido na compilação e não muda (tipagem estática). Veja: Tipos de Dados.
Tipagem estática
Cada variável tem um tipo fixo, conferido pelo compilador antes de rodar. Muitos erros são pegos cedo, na compilação. Veja: Tipos de Dados.

U

UB
Sigla de undefined behavior: veja Comportamento indefinido. Veja: Comportamento Indefinido.
unique_ptr / shared_ptr
Os dois ponteiros inteligentes principais. unique_ptr não pode ser copiado, só movido; shared_ptr pode ser copiado e apaga o objeto quando o último dono some. Veja: Ponteiros Inteligentes.
unordered_map
Como o std::map, mas sem ordem: usa uma tabela de espalhamento (hash) e costuma ser mais rápido para procurar. Veja: std::unordered_map.
unsigned (sem sinal)
Inteiro que não aceita negativos e, em troca, vai mais longe no positivo. v.size() devolve um sem sinal, por isso os avisos de -Wsign-compare. Veja: Inteiros.
using / typedef
Dão um apelido a um tipo: using Nota = double;. using namespace std; é outra coisa: traz todos os nomes de std (evite em cabeçalhos). Veja: using e typedef e Namespaces.

V

Variável
Um espaço na memória com nome e tipo, que guarda um valor: int idade = 30;. Veja: Variáveis.
variant C++17
Uma caixa que guarda um valor de um entre vários tipos possíveis: std::variant<int, std::string>. Veja: optional e variant.
vector (vetor)
O container mais usado: uma lista que cresce sozinha, com acesso direto por índice: std::vector<int> notas{7, 9};. Veja: std::vector.
View (visão) C++20
Uma "janela" sobre um range que mostra os itens de outro jeito (filtrados, transformados, invertidos) sem copiar: v | std::views::filter(…). Veja: Ranges.
virtual
Marca um método que as classes filhas podem substituir, e cuja versão é escolhida durante a execução, pelo tipo real do objeto. É o que faz o polimorfismo funcionar. Veja: Polimorfismo.
void
"Nada": o tipo de retorno de uma função que não devolve valor. Veja: Retorno.

W

-Wall -Wextra
As opções do compilador que ligam os avisos mais úteis. O guia compila sempre com elas. Veja: Avisos e Compilar com g++.
WebAssembly
Um formato de programa que roda dentro do navegador. O editor do guia compila o seu C++ com o Clang para WebAssembly e o roda na própria página. Veja: O Editor do Guia.
while / do-while
Laços que repetem enquanto a condição for verdadeira; o do-while roda pelo menos uma vez. Veja: while e do-while.
