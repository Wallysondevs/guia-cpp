Projeto Jogo de Adivinhação

O computador pensa num número de 1 a 100, e você tenta adivinhar. A cada palpite, ele diz "É maior!" ou "É menor!", até você acertar. No fim, mostra quantas tentativas você precisou e se bateu o recorde. É o projeto clássico de quem está aprendendo a programar, e por um bom motivo: ele junta decisões, laços, contadores, funções e números aleatórios num programa curto e divertido.

Você vai praticar
  • if e else if para as dicas.
  • O laço while ("até acertar") e o do-while ("jogar de novo?").
  • Contadores com ++.
  • Números aleatórios com <random>: gerador, distribuição e semente.
  • Funções e passagem por referência (e o que acontece sem ela).
  • Guardar o melhor resultado: o recorde.

Seis etapas até lá:

  1. Um palpite, com o número secreto fixo (if, else if).
  2. Repetir até acertar (while).
  3. Contar as tentativas (++).
  4. Sortear o número (<random> com semente fixa).
  5. Jogar de novo (funções, do-while, referência).
  6. Recorde, e a semente de verdade no código final.

Etapa 1 · Um palpite

Antes de sortear qualquer coisa, vamos fazer o jogo funcionar com um número secreto fixo: 42. Assim você sabe a resposta e consegue testar cada caminho do programa. Esse é um truque que todo programador usa: primeiro faça funcionar com valores conhecidos, depois troque pelos valores de verdade.

#include <iostream>

int main() {
    std::cout << "=== Adivinhe o número ===\n";
    const int secreto = 42;
    int palpite = 0;

    std::cout << "Seu palpite (1 a 100): ";
    std::cin >> palpite;

    if (palpite < secreto) {
        std::cout << "É maior!\n";
    } else if (palpite > secreto) {
        std::cout << "É menor!\n";
    } else {
        std::cout << "Acertou!\n";
    }
}
const int secreto = 42;
O número a adivinhar. É const porque não muda durante o jogo (veja Constantes).
if (palpite < secreto)
Se o palpite for menor que o secreto, o secreto é maior: a dica é "É maior!". Cuidado para não inverter: a dica fala do número secreto, não do palpite.
else if (palpite > secreto)
Senão, se o palpite for maior, a dica é "É menor!" (veja else if).
else
Nem menor nem maior: só pode ser igual. Acertou!

Etapa 2 · Repetir até acertar

Um palpite só não é jogo. Queremos repetir "pergunta, dica" enquanto o palpite for diferente do secreto. Essa frase já é o código: while (palpite != secreto) (veja while).

#include <iostream>

int main() {
    std::cout << "=== Adivinhe o número ===\n";
    const int secreto = 42;
    int palpite = 0;

    while (palpite != secreto) {
        std::cout << "Seu palpite (1 a 100): ";
        if (!(std::cin >> palpite)) {
            std::cout << "\nEntrada inválida. Fim do jogo.\n";
            return 1;
        }

        if (palpite < secreto) {
            std::cout << "É maior!\n";
        } else if (palpite > secreto) {
            std::cout << "É menor!\n";
        } else {
            std::cout << "Acertou!\n";
        }
    }
}
LinhaO que faz
int palpite = 0;Agora a variável precisa existir antes do laço, porque a condição do while a usa logo na primeira volta. Começa com 0, que nunca é o secreto: o laço sempre roda pelo menos uma vez.
while (palpite != secreto)"Enquanto o palpite for diferente do secreto, repita." Quando a pessoa acerta, a dica "Acertou!" aparece e a condição fica falsa: o laço termina.
if (!(std::cin >> palpite))Lê o palpite e confere se a leitura deu certo. Se a pessoa digitou um texto (ou a entrada acabou), encerra o jogo com return 1;. O porquê está logo abaixo.

Por que conferir a leitura: o laço infinito

Na etapa 1, se a Ana digitasse abc, o cin falhava, o palpite ficava 0 e o programa dizia "É maior!" e terminava. Com o laço e sem o if (!(std::cin >> palpite)), o cin fica em estado de falha, cada volta "lê" 0 sem esperar, e o laço nunca termina. Etapa 3 · Contar as tentativas

Quantos palpites a pessoa precisou? Para saber, usamos um contador: uma variável que começa em 0 e ganha 1 a cada palpite.

#include <iostream>

int main() {
    std::cout << "=== Adivinhe o número ===\n";
    const int secreto = 42;
    int palpite = 0;
    int tentativas = 0;

    while (palpite != secreto) {
        std::cout << "Seu palpite (1 a 100): ";
        if (!(std::cin >> palpite)) {
            std::cout << "\nEntrada inválida. Fim do jogo.\n";
            return 1;
        }
        ++tentativas;

        if (palpite < secreto) {
            std::cout << "É maior!\n";
        } else if (palpite > secreto) {
            std::cout << "É menor!\n";
        }
    }
    std::cout << "Acertou em " << tentativas << " tentativas!\n";
}
int tentativas = 0;
O contador, criado antes do laço. Se fosse criado dentro, voltaria a zero a cada volta.
++tentativas;
Soma 1 (veja ++ e --). Fica logo depois de uma leitura que deu certo: só conta palpites de verdade.
std::cout << "Acertou em " …
A mensagem de acerto saiu de dentro do laço e foi para depois dele. Quando o laço termina, é porque a pessoa acertou: é o lugar certo para comemorar e mostrar o total. Por isso o else sumiu.

Etapa 4 · Sortear o número

Hora de deixar o computador escolher. Números aleatórios em C++ moderno usam o cabeçalho <random> e duas peças, explicadas em detalhes na aula Números Aleatórios:

PeçaComparaçãoNo código
Gerador (motor)Uma máquina que solta números enormes, sem padrão aparente.std::mt19937 gerador(42);
DistribuiçãoUm "funil" que transforma esses números enormes num intervalo que você escolhe, com chances iguais.std::uniform_int_distribution<int> sorteio(1, 100);
SortearPassar o gerador pelo funil.sorteio(gerador)
#include <iostream>
#include <random>

int main() {
    std::cout << "=== Adivinhe o número ===\n";

    std::mt19937 gerador(42);  // semente fixa: sorteia sempre o mesmo número (bom para testar)
    std::uniform_int_distribution<int> sorteio(1, 100);
    const int secreto = sorteio(gerador);

    int palpite = 0;
    int tentativas = 0;
    std::cout << "Pensei num número de 1 a 100.\n";

    while (palpite != secreto) {
        std::cout << "Seu palpite (1 a 100): ";
        if (!(std::cin >> palpite)) {
            std::cout << "\nEntrada inválida. Fim do jogo.\n";
            return 1;
        }
        ++tentativas;

        if (palpite < secreto) {
            std::cout << "É maior!\n";
        } else if (palpite > secreto) {
            std::cout << "É menor!\n";
        }
    }
    std::cout << "Acertou em " << tentativas << " tentativas!\n";
}
std::mt19937
O gerador mais usado. O nome vem do algoritmo Mersenne Twister (mt) e do número 19937 que faz parte da matemática dele. Não precisa decorar.
gerador(42)
O 42 é a semente: o ponto de partida do gerador. A mesma semente produz sempre a mesma sequência de números. Parece um defeito, mas é ótimo para testar: o jogo fica previsível enquanto você o constrói.
std::uniform_int_distribution<int> sorteio(1, 100);
"Distribuição uniforme de inteiros": todos os números de 1 a 100 (incluindo os dois) têm a mesma chance.
const int secreto = sorteio(gerador);
Sorteia uma vez e guarda. Continua const: depois de sorteado, o secreto não muda.

Com a semente 42, o g++ da Ana sorteia o 38, e vai sortear 38 toda vez que o programa rodar. Um programa só para ver os primeiros sorteios, rodado duas vezes:

#include <iostream>
#include <random>

int main() {
    std::mt19937 gerador(42);
    std::uniform_int_distribution<int> sorteio(1, 100);
    for (int i = 0; i < 5; ++i) std::cout << sorteio(gerador) << ' ';
    std::cout << '\n';
    std::mt19937 g2(42);
    for (int i = 0; i < 3; ++i) std::cout << g2() << ' ';
    std::cout << '\n';
}

No editor do guia, o número sorteado pode ser outro

O C++ garante que o mt19937 com a mesma semente solta os mesmos números "crus" em qualquer computador (a segunda linha acima). Mas o "funil" (uniform_int_distribution) é escrito por cada biblioteca do seu jeito. O g++ (biblioteca libstdc++) dá 38 com a semente 42; o editor do guia usa o Clang com outra biblioteca, e pode sortear outro número com a mesma semente. Por isso as missões a partir daqui não dependem de qual número sai: a entrada da missão chuta 1, 2, 3, … até 100, todos na mesma linha, e para quando acerta.

Esqueceu o #include <random>

O que significa: "mt19937 não é membro de std": sem o cabeçalho, o compilador não conhece o gerador. O segundo erro é consequência do primeiro: como a linha 6 falhou, a variável gerador não existe. Como consertar: #include <random>. Inclua sempre o cabeçalho de tudo o que você usa.

Etapa 5 · Jogar de novo

Para jogar várias partidas, o jeito mais limpo é transformar "uma partida" numa função e chamá-la num do-while, como o "Outra conta?" da Calculadora. Vamos criar três funções:

FunçãoTarefa
int ler_palpite()Pergunta e lê um palpite. Se a leitura falhar, encerra o jogo.
int jogar(std::mt19937& gerador)Sorteia o número, joga uma partida inteira e devolve o número de tentativas.
bool quer_jogar_de_novo()Pergunta "Jogar de novo? (s/n)".
#include <cstdlib>
#include <iostream>
#include <random>
#include <string>

// Lê um palpite. Se a entrada acabar ou não for número, encerra o jogo.
int ler_palpite() {
    int palpite = 0;
    std::cout << "Seu palpite (1 a 100): ";
    if (!(std::cin >> palpite)) {
        std::cout << "\nEntrada inválida. Fim do jogo.\n";
        std::exit(1);
    }
    return palpite;
}

// Joga uma partida e devolve quantas tentativas foram precisas.
int jogar(std::mt19937& gerador) {
    std::uniform_int_distribution<int> sorteio(1, 100);
    const int secreto = sorteio(gerador);
    int palpite = 0;
    int tentativas = 0;
    std::cout << "Pensei num número de 1 a 100.\n";

    while (palpite != secreto) {
        palpite = ler_palpite();
        ++tentativas;
        if (palpite < secreto) {
            std::cout << "É maior!\n";
        } else if (palpite > secreto) {
            std::cout << "É menor!\n";
        }
    }
    std::cout << "Acertou em " << tentativas << " tentativas!\n";
    return tentativas;
}

bool quer_jogar_de_novo() {
    std::string resto;
    std::getline(std::cin, resto);  // descarta o resto da linha do último palpite
    char resposta = 'n';
    std::cout << "Jogar de novo? (s/n): ";
    std::cin >> resposta;
    return resposta == 's' || resposta == 'S';
}

int main() {
    std::cout << "=== Adivinhe o número ===\n";
    std::mt19937 gerador(42);  // semente fixa, para testar

    do {
        jogar(gerador);
    } while (quer_jogar_de_novo());

    std::cout << "Até a próxima!\n";
}
std::exit(1);
Dentro de ler_palpite, um return só sairia da função. Para encerrar o programa inteiro de dentro de uma função, usamos std::exit, do <cstdlib>.
int jogar(std::mt19937& gerador)
O & é essencial: a função recebe o mesmo gerador do main, por referência. Cada partida avança o gerador, e a próxima sorteia um número novo. Veja o cenário abaixo para o que acontece sem o &.
std::uniform_int_distribution<int> sorteio(1, 100);
A distribuição pode ser criada dentro de jogar: ela é só o "funil" e não guarda nada importante entre uma partida e outra.
return tentativas;
A partida devolve quantas tentativas foram precisas. Nesta etapa o main ainda ignora esse valor; na etapa 6 ele vira o recorde.
std::getline(std::cin, resto);
Em quer_jogar_de_novo: descarta o que sobrou na linha do último palpite. Se a pessoa digitou 38 40, o >> leu o 38 (e acertou), e o 40 ainda está lá. Sem o descarte, ele seria lido como resposta da pergunta seguinte.
std::mt19937 gerador(42);
Agora o gerador mora no main e é criado uma vez só, antes de todas as partidas.

A semente de verdade

O jogo está pronto, mas com a semente 42 a primeira partida é sempre o 38. Para o jogo de verdade, a semente precisa mudar a cada vez que o programa roda. Quem fornece essa semente é o std::random_device, que pede ao sistema operacional um número imprevisível (veja Números Aleatórios). Uma linha muda:

    std::mt19937 gerador(std::random_device{}());  // semente real: muda a cada execução
std::random_device{}
Cria um random_device temporário (as chaves vazias criam o objeto).
()
Chama esse objeto para obter um número imprevisível.
gerador(…)
Esse número vira a semente do mt19937.

Por que não usar o random_device para sortear tudo? Ele pode ser lento (às vezes conversa com o hardware). O costume é usá-lo uma vez, para a semente, e deixar o mt19937, que é rápido, fazer o resto.

Exercícios

1. O palpite foi 30 e o número secreto é 42. Qual dica o jogo deve mostrar?

2. Com std::mt19937 gerador(42);, o que acontece ao rodar o programa várias vezes?

3. Por que jogar recebe std::mt19937& gerador, com &?

4. Onde deve ser criada a variável recorde?

5. Complete a distribuição que sorteia números de 1 a 6, como um dado:

std::uniform_int_distribution<int> dado();

6. Complete o laço que repete enquanto a pessoa não acertar:

while (palpite secreto) {

Resumo

  • Comece com valores fixos (secreto = 42) para testar; troque pelos valores de verdade no fim.
  • while (palpite != secreto) repete até acertar; um contador ++tentativas conta os palpites.
  • Laço que lê do teclado precisa conferir a leitura (if (!(std::cin >> x))), senão vira laço infinito.
  • <random>: um gerador (std::mt19937), uma distribuição (uniform_int_distribution) e uma semente. Semente fixa = sequência repetível (por compilador); std::random_device{}() = semente que muda.
  • Passe o gerador por referência (&), senão cada chamada usa uma cópia e repete os números.
  • O recorde mora fora do laço e começa num valor que significa "nenhum".
