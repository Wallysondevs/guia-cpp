C++ std::format e std::print

Na aula anterior, você montou a tabela de notas da Ana com std::cout, std::setw, std::left, std::fixed… e muitos <<. Funciona, mas é comprido e as configurações "grudam". O C++ moderno trouxe um jeito mais curto, inspirado em Python: você escreve o texto com buracos marcados por {}, e o C++ preenche cada buraco com um valor. Isso é o std::format C++20. E o std::println C++23 faz o mesmo e já mostra na tela, pulando a linha.

Você vai aprender
  • Como o {} funciona e a diferença entre std::format, std::print e std::println.
  • Casas decimais ({:.2f}), largura e alinhamento ({:>10}), zeros à esquerda ({:05}), hexadecimal ({:x}).
  • Argumentos numerados ({0}, {1}) e como escrever uma chave de verdade ({{).
  • A mesma tabela de notas com cout + iomanip e com println, lado a lado.
  • Como mostrar 1.234,50 no formato brasileiro, com {:L} e o locale.
  • Por que um erro no texto de formato aparece já na compilação, e qual -std= cada recurso exige.

Todos os programas desta aula foram compilados com o g++ 15.2 na máquina fictícia da Ana (usuária ana, computador notebook), com g++ -std=c++23 -Wall -Wextra arquivo.cpp -o programa. Aqui o -std=c++23 é obrigatório (seção 6).

A ideia: o formulário com lacunas

Pense num formulário impresso: "Eu, ______, com ______ anos, declaro…". Você não reescreve o formulário inteiro para cada pessoa: só preenche as lacunas. No std::format, o texto com lacunas se chama string de formato, e cada lacuna é um par de chaves {}:

JeitoCódigo
coutstd::cout << nome << " tem " << idade << " anos.\n";
formatstd::cout << std::format("{} tem {} anos.\n", nome, idade);
printlnstd::println("{} tem {} anos.", nome, idade);

As três linhas mostram a mesma coisa. Com as lacunas, você enxerga a frase inteira de uma vez, sem picotá-la em pedaços.

1. std::format: o {}

#include <format>
#include <iostream>
#include <string>

int main() {
    std::string nome = "Ana";
    int idade = 29;
    std::string frase = std::format("{} tem {} anos.", nome, idade);
    std::cout << frase << "\n";
}

$ g++ -std=c++23 -Wall -Wextra ola.cpp -o ola
$ ./ola
Ana tem 29 anos.
#include <format>
Traz o std::format (C++20).
"{} tem {} anos."
A string de formato. Cada {} é uma lacuna. Tudo o mais é copiado como está.
nome, idade
Os argumentos, os valores que preenchem as lacunas, na ordem: o primeiro {} recebe nome, o segundo recebe idade.
std::string frase = …
O std::format não mostra nada: ele devolve um texto (std::string, aula Strings) pronto. Você pode guardá-lo, juntá-lo com outros, gravá-lo num arquivo, ou mostrá-lo com cout.

Qualquer tipo básico entra numa lacuna: textos, inteiros, double, char, e até bool, que sai como true/false (sem precisar de boolalpha).

3. Dentro das chaves: as especificações

Uma lacuna pode levar instruções de como mostrar o valor. Elas vêm depois de dois-pontos: {:especificação}. É o mesmo trabalho dos manipuladores da aula anterior, numa linguagem curtinha:

#include <format>
#include <iostream>

int main() {
    std::cout << std::format("Preço: R$ {:.2f}", 19.9) << "\n";
    std::cout << std::format("[{:>10}]", "Ana") << "\n";
    std::cout << std::format("[{:<10}]", "Ana") << "\n";
    std::cout << std::format("[{:^10}]", "Ana") << "\n";
    std::cout << std::format("[{:*^10}]", "Ana") << "\n";
    std::cout << std::format("[{:05}]", 42) << "\n";
    std::cout << std::format("{:x} {:X} {:#x} {:b}", 255, 255, 255, 5) << "\n";
}

$ ./basico
Preço: R$ 19.90          « {:.2f}: duas casas
[       Ana]             « {:>10}: largura 10, à direita
[Ana       ]             « {:<10}: à esquerda
[   Ana    ]             « {:^10}: centralizado
[***Ana****]             « {:*^10}: centralizado, preenchendo com *
[00042]                  « {:05}: largura 5 com zeros
ff FF 0xff 101           « hexadecimal, maiúsculo, com 0x, e binário

A especificação segue sempre a mesma ordem. Você só escreve as partes de que precisa:

ParteExemploO que faz
preenchimento + alinhamento*^, <, >, ^< esquerda, > direita, ^ centro. Um caractere antes do sinal é o preenchimento (padrão: espaço).
sinal+Mostra + também nos positivos: {:+} com 5 → +5.
##xMostra o prefixo da base (0x, 0b).
0 + largura05Completa com zeros à esquerda (só para números).
largura10Largura mínima do campo.
. precisão.2Com f: casas decimais. Num texto: corta no tamanho.
tipof, e, x, X, b, o, df ponto fixo, e notação científica, x hexadecimal, b binário, o octal, d decimal.

Exemplo completo: {:*>10.2f} = "preencha com *, alinhe à direita, largura 10, duas casas, ponto fixo". Sem alinhamento, os textos vão à esquerda e os números à direita: {:10} com "Ana" dá [Ana ], e com 42 dá [ 42].

Nada gruda

Cada lacuna tem a sua especificação, que vale só para ela. Não existe o problema da aula de iomanip, em que um std::fixed esquecido muda o resto do programa.

4. Argumentos numerados e chaves de verdade

Dentro das chaves, antes dos dois-pontos, você pode dizer qual argumento usar, começando do zero. Assim dá para repetir um valor ou trocar a ordem:

#include <format>
#include <iostream>

int main() {
    std::cout << std::format("{0} e {1}; {1} e {0}", "Ana", "Bruno") << "\n";
    std::cout << std::format("{{chaves}} {}", 1) << "\n";
}

$ ./numerados
Ana e Bruno; Bruno e Ana
{chaves} 1               « {{ vira {, e }} vira }
{0}, {1}
O argumento número 0 ("Ana") e o número 1 ("Bruno"). Com número e especificação: {1:>8}.
{{ e }}
Para escrever uma chave de verdade no texto, dobre-a.

Não dá para misturar os dois estilos na mesma string: ou todas as lacunas têm número, ou nenhuma tem.

7. O formato brasileiro: {:L} e o locale

O std::format sempre usa ponto decimal e nenhum separador de milhar: 1234567.89. Isso é proposital: o resultado é o mesmo em qualquer computador, o que é ótimo para arquivos e dados. Para mostrar ao usuário brasileiro 1.234.567,89, você precisa de duas coisas:

  1. a letra L na especificação ({:L}, {:.2Lf}), que quer dizer "use as regras do locale";
  2. um locale brasileiro. Locale ("local") é o pacote de costumes de um lugar: vírgula ou ponto, separador de milhar, formato de data. O do Brasil se chama pt_BR.UTF-8.
#include <format>
#include <iostream>
#include <locale>

int main() {
    double v = 1234567.891;
    std::cout << std::format("{:.2f}", v) << "\n";
    std::cout << std::format("{:L}", v) << "\n";
    std::cout << std::format(std::locale("pt_BR.UTF-8"), "{:.2Lf}", v) << "\n";
    std::cout << std::format(std::locale("pt_BR.UTF-8"), "{:L}", 1234567) << "\n";
}

$ g++ -std=c++23 -Wall -Wextra local.cpp -o local
$ ./local
1234567.89               « sem L: ponto, sem separador
1234567.891              « L sozinho: o locale padrão do programa é o "C", americano
1.234.567,89             « L + locale pt_BR: formato brasileiro
1.234.567
#include <locale>
Traz o std::locale.
std::locale("pt_BR.UTF-8")
Carrega as regras brasileiras do sistema operacional.
std::format(locale, "...", v)
Quando o primeiro argumento é um locale, as lacunas com L seguem as regras dele.
{:L} sem locale
Repare na segunda linha: mesmo com o Linux da Ana em português, o programa começa no locale "C" (o "neutro", americano). O L não mudou nada.

Para não repetir o locale em toda chamada, você pode trocar o locale do programa inteiro no começo do main. O std::locale("") (texto vazio) quer dizer "o locale de quem está usando o computador", lido da variável LANG (pt_BR.UTF-8 na máquina da Ana):

    std::locale::global(std::locale(""));
    std::cout << std::format("{:L}", 1234.5) << "\n";
    std::cout << std::format("R$ {:.2Lf}", 1234.5) << "\n";
    std::cout << std::format("{:.2f}", 1234.5) << "\n";

$ ./global

R$ 1.234,50
1234.50                  « sem o L, continua com ponto
O locale precisa existir no sistema

Os locales vêm do sistema operacional. Se o pt_BR.UTF-8 não estiver instalado (é comum em servidores e contêineres), o programa compila, mas morre ao rodar. Com um nome inexistente:

"O nome do locale não é válido". Isso é uma exceção (aula Exceções) que ninguém tratou, e o programa foi encerrado. No Ubuntu, o locale brasileiro vem com o pacote language-pack-pt. O editor do guia roda no navegador, sem os locales do sistema: lá, rode só os exemplos sem std::locale.

8. Erros de formato aparecem na compilação

A string de formato precisa estar escrita no código

Para poder conferir, o compilador precisa ver a string. Guardá-la numa variável não funciona:

$ g++ -std=c++23 -Wall -Wextra var.cpp -o var      « std::string modelo = "Olá, {}!"; std::format(modelo, "Ana")
var.cpp: In function ‘int main()’:

    7 |     std::cout << std::format(modelo, "Ana") << "\n";
      |                              ^~~~~~

Escreva o texto entre aspas direto na chamada. (Para os raros casos em que o formato só é conhecido com o programa rodando, existe o std::vformat, que confere durante a execução; você não vai precisar dele tão cedo.)

Quando dá errado

error: ‘format’ is not a member of ‘std’ / ‘print’ is not a member of ‘std’

O que significa: há duas causas. Se a nota diz only available from C++20 onwards (ou C++23), faltou o -std=c++23 no comando. Se não diz, faltou o #include <format> ou #include <print>.

Como consertar: compile com g++ -std=c++23 -Wall -Wextra … e confira os #include.

error: call to consteval function … is not a constant expression

O que significa: a string de formato tem um problema: lacunas a mais, chave sem par, especificação que não serve para o tipo, ou não está escrita direto na chamada.

Como consertar: procure, mais abaixo na mensagem, o nome com __ (como __invalid_arg_id_in_format_string) e use a tabela da seção 8. Conte as lacunas e os argumentos.

terminate called after throwing an instance of 'std::runtime_error' … name not valid

O que significa: o locale pedido (por exemplo, pt_BR.UTF-8) não está instalado no computador onde o programa rodou.

Como consertar: instale o locale (no Ubuntu, sudo apt install language-pack-pt) ou não dependa dele: mostre com ponto, ou troque o ponto pela vírgula no texto pronto.

Apareceu {} na tela em vez do valor

O que significa: você usou std::cout << "Olá, {}", sem std::format. O cout não entende lacunas: mostra o texto como está.

Como consertar: std::cout << std::format("Olá, {}", nome) ou std::println("Olá, {}", nome).

Resumo

  • std::format("… {} …", valores) C++20 devolve um std::string; std::print e std::println C++23 mostram na tela (o println pula a linha).
  • Especificações depois de : — {:.2f} casas, {:<10}/{:>10}/{:^10} alinhamento, {:05} zeros, {:x} hexadecimal. Nada gruda.
  • {0}, {1} escolhem o argumento; {{ e }} escrevem chaves.
