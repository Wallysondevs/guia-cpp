C++ Containers

Os containers (recipientes) da biblioteca padrão guardam coleções de valores: uma lista que cresce, um dicionário, um conjunto sem repetidos, uma pilha, uma fila. Esta página reúne os onze mais usados: qual cabeçalho incluir, quando usar cada um, quanto custa cada operação e os métodos principais, com exemplo e o resultado real (83 exemplos compilados e executados com o g++ 15.2, -std=c++23). Para aprender com calma, comece por O que é a STL e std::vector.

Como ler as tabelas
  • Cada container tem uma declaração inicial (no título da tabela). Cada exemplo começa dela, do zero.
  • Nos métodos que mudam o container, o resultado mostra como ele ficou, no formato do std::println("{}", c) C++23: [10, 20] para sequências, {10, 20} para conjuntos, {"ana": 9} para mapas.
  • Nos unordered_…, a ordem mostrada é a que saiu no laboratório; em outro compilador (até no editor do guia) pode ser outra.
  • Posições começam em 0. begin() é um iterador para o primeiro elemento; end(), para "depois do último".

Exemplo rápido

#include <map>
#include <print>
#include <set>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> compras{"pão", "leite", "café", "leite"};
    compras.push_back("ovos");
    std::println("lista: {} ({} itens)", compras, compras.size());

    std::set<std::string> semRepetir(compras.begin(), compras.end());
    std::println("sem repetir: {}", semRepetir);

    std::map<std::string, int> quantos;
    for (const auto& item : compras) {
        ++quantos[item];
    }
    std::println("quantos: {}", quantos);
}

$ g++ -std=c++23 -Wall -Wextra colecoes.cpp -o colecoes
$ ./colecoes
lista: ["pão", "leite", "café", "leite", "ovos"] (5 itens)
sem repetir: {"café", "leite", "ovos", "pão"}
quantos: {"café": 1, "leite": 2, "ovos": 1, "pão": 1}

O mesmo item, três containers: o vector guarda tudo na ordem em que entrou (com o "leite" repetido), o set guarda cada um uma vez, em ordem, e o map associa cada item a um número. O set e o map ordenam comparando bytes, e por isso "pão" (com ã) veio depois de "ovos".

stack, queue e priority_queue são adaptadores: por dentro usam um deque (ou um vector, no caso da priority_queue) e só mostram as operações permitidas. Por isso não têm begin()/end() e não dá para percorrê-los com for. Desde o C++23 existem também std::flat_map e std::flat_set (<flat_map>, <flat_set>), mapas e conjuntos ordenados guardados num vetor; o g++ 15 já os tem.

Complexidade

Quanto o tempo de cada operação cresce quando o container cresce (n = número de elementos). O(1): constante, não depende do tamanho. O(log n): cresce muito devagar (um milhão de elementos ≈ 20 passos). O(n): proporcional ao tamanho. "Amortizado": quase sempre O(1); de vez em quando, uma operação cara (o vector realocando) que, dividida por todas, some.

Qual usar

Você precisa de…Use
Uma lista de coisas, na ordem, que cresce. (Na dúvida, é esta.)std::vector
Um número fixo de elementos, sabido ao escrever o código (os 12 meses, as 3 notas).std::array
Achar um valor pela chave (nome → telefone) e listar em ordem.std::map
Achar pela chave o mais rápido possível, sem ligar para a ordem.std::unordered_map
Saber se algo já apareceu; tirar repetidos.std::set (ordenado) ou std::unordered_set
Desfazer (Ctrl+Z), conferir parênteses, voltar pelo caminho.std::stack
Atender na ordem de chegada (fila do caixa, tarefas).std::queue
Atender sempre o mais urgente primeiro.std::priority_queue
Inserir e tirar muito nas duas pontas, com acesso por posição.std::deque
Inserir e remover no meio sem invalidar os outros iteradores.std::list (raramente: na prática o vector costuma ser mais rápido até nisso, por causa da memória contígua)

Iteradores invalidados

Depois de um push_back, insert ou erase num vector, iteradores, ponteiros e referências para os elementos podem ficar inválidos (o vetor pode ter mudado de lugar na memória). Usá-los é comportamento indefinido. Não guarde &v[0] ou v.begin() e depois acrescente elementos. map, set e list não têm esse problema (só o elemento apagado fica inválido).

Missão: a Ana lançou as notas da turma num vector. Mostre as notas diferentes, em ordem crescente, separadas por espaço, e quantas são. Dica: um container desta página faz as duas coisas sozinho, e ele pode ser criado direto do vetor: C diferentes(notas.begin(), notas.end());.

    }
