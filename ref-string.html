C++ std::string

Os métodos de std::string e as funções livres que trabalham com texto, agrupados pelo que fazem. Cada linha tem a assinatura simplificada, uma explicação curta, um exemplo e o resultado real: todos os 82 exemplos foram compilados juntos e executados com o g++ 15.2 (-std=c++23) na máquina da Ana. Para aprender com calma, veja as aulas Strings, Funções de String e Texto ↔ Número.

Como ler as tabelas
  • Em todos os exemplos, s começa como std::string s = "banana";, a não ser que a célula mostre outra declaração. Cada exemplo começa do zero.
  • Nos métodos que mudam o texto, o resultado mostra como s ficou: s = "bananas".
  • Índices começam em 0: em "banana", o b está na posição 0 e o último a na 5.
  • size_type é std::size_t, um inteiro sem sinal. npos (std::string::npos) é o maior valor dele (18446744073709551615 aqui) e quer dizer "não achei" ou "até o fim".
  • As assinaturas estão simplificadas: a maioria dos métodos também aceita const char*, std::string_view ou um char no lugar de const string&.
  • size() e as posições contam bytes, não letras: um é ocupa 2 (veja Acentos e UTF-8).

Exemplo rápido

#include <iostream>
#include <string>

int main() {
    std::string s = "banana";
    std::cout << s.size() << '\n';
    std::cout << s.find("na") << '\n';
    std::cout << s.substr(1, 3) << '\n';

    s.replace(0, 1, "C");
    std::cout << s << '\n';

    if (s.find("x") == std::string::npos) {
        std::cout << "não tem x\n";
    }
}

$ ./banana

substr(início, tamanho), não (início, fim)

Quem vem de Java, JavaScript ou Python espera que o segundo número seja a posição final. Em C++ é o tamanho do pedaço: s.substr(1, 3) são 3 caracteres a partir da posição 1. Tamanho além do fim não é erro (pega até onde der); início além do fim é.

Sempre compare com npos

find devolve um size_t, nunca −1. Escreva if (s.find("x") != std::string::npos). Um if (s.find("x")) está errado duas vezes: npos é "verdadeiro" e a posição 0, "falso". Se a pergunta é só "tem ou não tem?", use contains (C++23).

getline × >>

O >> lê uma palavra (para no espaço); o getline lê a linha inteira:

#include <iostream>
#include <string>

int main() {
    std::string nome;
    std::cout << "Nome completo: ";
    std::getline(std::cin, nome);
    std::cout << "Olá, " << nome << "! (" << nome.size() << " bytes)\n";

    std::string primeiro;
    std::cout << "De novo: ";
    std::cin >> primeiro;
    std::cout << "Com >>: " << primeiro << '\n';
}

$ g++ -std=c++23 -Wall -Wextra nome.cpp -o nome
$ ./nome
Nome completo: Ana Maria Souza
Olá, Ana Maria Souza! (15 bytes)
De novo: Bruno Lima
Com >>: Bruno

Cuidado ao misturar os dois na ordem contrária: depois de um std::cin >> idade;, o Enter fica esperando, e o próximo getline lê uma linha vazia. A aula getline mostra o problema e o std::ws que resolve.

Missão: o programa deve mostrar só o nome do arquivo, notas.txt, a partir do caminho. Ache a última barra com um método da tabela Procurar e pegue o resto com substr.

#include <iostream>
#include <string>

int main() {
    std::string caminho = "/home/ana/notas.txt";
    std::size_t barra = caminho.find_last_of('/');
    std::string arquivo = caminho.substr(barra + 1);
    std::cout << arquivo << '\n';
}
