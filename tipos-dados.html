C++ Tipos de Dados

Toda variável em C++ tem um tipo, escolhido quando ela é criada: int idade, double altura. O tipo diz que espécie de valor cabe na caixa, quanto espaço ela ocupa na memória e o que dá para fazer com ela (somar, juntar textos, perguntar se é verdade). Esta aula é o mapa: mostra os tipos que você vai usar o tempo todo, o tamanho real de cada um e como escolher. Cada família tem depois a sua própria aula.

Você vai aprender
  • Os tipos do dia a dia: int, double, char, bool e std::string.
  • Os "parentes": short, long, long long, float, long double.
  • Como medir o tamanho de um tipo com sizeof, e os tamanhos reais no Linux da Ana.
  • Como escolher o tipo certo para cada informação.
  • A diferença entre tipos fundamentais (da linguagem) e tipos da biblioteca (como std::string).

Todos os programas desta aula foram compilados com o g++ 15.2 na máquina fictícia da Ana (usuária ana, computador notebook, um PC comum de 64 bits), na pasta ~/cpp, com o comando padrão do guia: g++ -std=c++23 -Wall -Wextra arquivo.cpp -o programa.

A ideia: cada coisa no seu recipiente

Na cozinha, cada coisa tem o seu recipiente: ovos vão na caixa de ovos, leite vai na garrafa, açúcar vai no pote. Você até consegue pôr leite na caixa de ovos, mas vai dar errado. E ninguém guarda uma colher de sal num balde.

Os tipos do C++ são esses recipientes. Escolher o tipo é responder três perguntas:

  1. Que espécie de informação? Número inteiro, número com vírgula, uma letra, sim/não, um texto.
  2. De que tamanho? A idade de uma pessoa cabe num recipiente pequeno; a população do mundo precisa de um grande.
  3. Com que precisão? Um preço precisa de centavos; o número de alunos, não.

2. Medir o tamanho: sizeof

A memória do computador é medida em bytes. Um byte é um pedacinho de memória com 8 bits (cada bit é um 0 ou 1) e consegue guardar 256 valores diferentes. Quanto mais bytes um tipo tem, maiores (ou mais precisos) os números que ele guarda.

O operador sizeof ("tamanho de") responde quantos bytes um tipo ocupa:

#include <iostream>
#include <string>

int main() {
    std::cout << "bool:        " << sizeof(bool) << "\n";
    std::cout << "char:        " << sizeof(char) << "\n";
    std::cout << "short:       " << sizeof(short) << "\n";
    std::cout << "int:         " << sizeof(int) << "\n";
    std::cout << "long:        " << sizeof(long) << "\n";
    std::cout << "long long:   " << sizeof(long long) << "\n";
    std::cout << "float:       " << sizeof(float) << "\n";
    std::cout << "double:      " << sizeof(double) << "\n";
    std::cout << "long double: " << sizeof(long double) << "\n";
    std::cout << "std::string: " << sizeof(std::string) << "\n";
}

$ g++ -std=c++23 -Wall -Wextra tamanhos.cpp -o tamanhos
$ ./tamanhos

long:        8

Os tamanhos não são iguais em todo computador

A norma do C++ só garante mínimos: int tem pelo menos 2 bytes, long pelo menos 4, long long pelo menos 8. Os números acima valem para o Linux 64 bits da Ana. No Windows, por exemplo, long tem 4 bytes. No editor do guia, que roda num computador "de 32 bits" simulado (WebAssembly), long também tem 4 bytes (conferido com o Clang para esse alvo), e std::string dá outro número, porque o editor usa outra biblioteca padrão. Quando o tamanho exato importa, use long long ou os tipos de tamanho fixo, como std::int64_t (aula Inteiros).

sizeof de uma variável, e o mistério do std::string

sizeof também mede uma variável. Com variável, os parênteses são opcionais:

#include <iostream>
#include <string>

int main() {
    int idade = 29;
    std::string curto = "Ana";
    std::string longo = "Ana Clara de Souza Albuquerque, moradora de Recife";
    std::cout << sizeof(idade) << " " << sizeof idade << "\n";
    std::cout << sizeof(curto) << " " << sizeof(longo) << "\n";
    std::cout << curto.size() << " " << longo.size() << "\n";
}

$ g++ -std=c++23 -Wall -Wextra sizeofvar.cpp -o sizeofvar
$ ./sizeofvar
4 4
32 32                    « o mesmo tamanho para 3 e para 50 letras?
3 50                     « .size() conta as letras de verdade

Como um texto de 50 letras cabe em 32 bytes? Não cabe. O std::string é como uma ficha de biblioteca: a ficha tem sempre o mesmo tamanho (32 bytes) e diz onde está o livro. Textos curtos cabem na própria ficha; textos longos ficam guardados em outra parte da memória, e a ficha só aponta para lá. O sizeof mede a ficha; para saber quantas letras o texto tem, use .size() (aula Funções de String).

Na dúvida, a pergunta é "o que eu quero guardar?". Esta tabela resolve quase todos os casos:

Telefone não é número

Você nunca vai somar dois telefones. E números assim têm zeros à esquerda (01310), traços e parênteses que um int jogaria fora. Regra: se você não faz contas com aquilo, guarde como texto.

O que acontece com o tipo errado

O tipo errado raramente dá erro de compilação. Na maioria das vezes, o programa roda e dá a resposta errada:

#include <iostream>

int main() {
    int preco = 4.99;
    int pesoKg = 2.5;
    double total = preco * pesoKg;
    std::cout << "Total: " << total << "\n";
}

$ g++ -std=c++23 -Wall -Wextra errado.cpp -o errado
$ ./errado
Total: 8                 « 4 × 2: os centavos e o meio quilo sumiram

O int jogou fora a parte depois do ponto (4.99 virou 4; 2.5 virou 2), e o g++ não avisou com -Wall -Wextra. A aula Variáveis mostra como a inicialização com chaves (int preco{4.99};) transforma esse silêncio em erro.

Missão: conserte os tipos (só os tipos, sem mudar os números) para o total da feira da Ana sair certo: Total: 12.475. (No editor, o Clang ainda mostra avisos sobre a conversão: leia-os, eles apontam exatamente as linhas a consertar.)

int main() {

    int pesoKg = 2.5;
    double total = preco * pesoKg;
    std::cout << "Total: " << total << "\n";
}

4. Tipos fundamentais × tipos da biblioteca

Você deve ter reparado que quatro tipos são escritos "pelados" (int, double, char, bool) e um tem std:: na frente e pede um #include (std::string). Não é por acaso.

O void ("vazio") é o tipo fundamental que quer dizer "nenhum valor"; ele aparece nas funções que não devolvem nada. E a partir do Nível 2 você vai criar os seus próprios tipos, com structs e classes, do mesmo jeito que a biblioteca criou o std::string.

E se eu esquecer o #include <string>?

No laboratório, um programa com std::string e só #include <iostream> compilou e rodou, no g++ e no Clang, porque o <iostream> da biblioteca de hoje já traz o <string> junto, "de carona". Mas a norma não garante essa carona, e outra versão do compilador pode recusar o mesmo arquivo. Regra do guia: usou, inclua.

Quando dá errado

O programa compila, mas o número perde a parte depois do ponto

O que significa: um valor com vírgula foi parar numa variável inteira (int, long…), e a fração foi jogada fora.

Como consertar: use double para medidas e preços. Inicialize com chaves ({ }) para o compilador barrar esse corte.

error: ‘string’ was not declared in this scope

O que significa: faltou o std:: (ou o #include <string>).

Como consertar: escreva std::string e confira o #include <string> no topo.

error: invalid conversion from ‘const char*’ to ‘char’ (ou to ‘int’)

O que significa: um texto entre aspas duplas foi posto numa variável que não é de texto.

Como consertar: para texto, std::string. Para um único caractere, char com aspas simples: 'A'. A diferença é explicada em Caracteres.

O sizeof deu um número diferente do da tabela

O que significa: você está em outro sistema (Windows, 32 bits, o editor do guia em WebAssembly). Os tamanhos dependem da plataforma.

Como consertar: nada a consertar. Se o seu programa depende de um tamanho exato, use long long ou os tipos de <cstdint>, como std::int32_t (aula Inteiros).

Resumo

  • O tipo diz que valor cabe na variável, quanto espaço ela ocupa e o que dá para fazer com ela.
  • Os cinco do dia a dia: int (inteiro), double (com vírgula), char (um caractere, 'A'), bool (true/false) e std::string (texto, "Ana").
  • sizeof mede bytes. No Linux 64 bits: bool/char 1, short 2, int/float 4, long/long long/double 8, long double 16, std::string 32. Outros sistemas podem diferir.
  • Escolha pelo que você guarda: contagem → int; medida → double; sim/não → bool; texto (inclusive telefone e CEP) → std::string.
  • Tipo errado quase sempre compila e dá resposta errada.
  • Fundamentais (int, double…) são da linguagem; os da biblioteca (std::string, std::vector) pedem #include e std::.
