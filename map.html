C++ std::map

A Ana quer controlar o estoque da lojinha: 12 maçãs, 30 bananas, 8 peras. Com um vector, ela teria que guardar os nomes num vetor, as quantidades em outro, e procurar "pera" item por item. O std::map resolve isso: ele guarda pares "chave → valor" ("pera" → 8) e acha o valor pela chave, direto, como um dicionário acha a definição pela palavra. E ainda mantém tudo em ordem alfabética.

Você vai aprender
  • O que é um std::map e como criar um: std::map<std::string, int>.
  • Três jeitos de inserir: [], insert e emplace, e a diferença entre eles.
  • Três jeitos de ler: [] (que cria a chave sem querer), at (que lança std::out_of_range) e find/contains.
  • Como percorrer em ordem com for (const auto& [nome, qtd] : estoque).
  • Como apagar com erase.
  • O clássico: contar quantas vezes cada palavra aparece num texto.

Todos os programas desta aula foram compilados com o g++ 15.2 na máquina fictícia da Ana, na pasta ~/cpp/map, com g++ -std=c++23 -Wall -Wextra arquivo.cpp -o programa. É bom conhecer O que é a STL e Iteradores.

A ideia: o caderno de estoque

A Ana tem um caderno com uma linha por produto, em ordem alfabética: "banana ... 30", "maçã ... 12", "pera ... 8". Para saber quantas peras tem, ela não lê o caderno inteiro: vai direto na letra P. Cada produto aparece uma vez só; se chegam mais peras, ela corrige o número da linha "pera", não escreve outra linha.

No cadernoNo std::mapExemplo
O nome do produtoA chave (key): única, não se repete"pera"
A quantidadeO valor (value)8
Uma linha do cadernoUm par chave-valor{"pera", 8}
A ordem alfabéticaO map mantém as chaves sempre ordenadasbanana, maçã, pera

Em outras linguagens isso se chama "dicionário" (Python), "array associativo" (PHP) ou "objeto" (JavaScript). map quer dizer "mapa", no sentido de "mapear": ligar cada chave a um valor.

1. Criar e usar com []

#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> estoque{
        {"maçã", 12},
        {"banana", 30},
    };

    estoque["pera"] = 8;
    estoque["maçã"] = 15;

    std::cout << "Maçãs: " << estoque["maçã"] << '\n';
    std::cout << "Peras: " << estoque["pera"] << '\n';
    std::cout << "Produtos diferentes: " << estoque.size() << '\n';
}
#include <map>
O cabeçalho do std::map.
std::map<std::string, int>
Um template com dois tipos: o da chave (std::string, o nome) e o do valor (int, a quantidade).
{{"maçã", 12}, {"banana", 30},}
Já cria com dois pares. Cada par vai entre chaves: {chave, valor}. A vírgula depois do último é permitida.
estoque["pera"] = 8;
Se a chave "pera" não existe, ela é criada com o valor 8.
estoque["maçã"] = 15;
Se a chave já existe, o valor é trocado: a maçã passa de 12 para 15. Não aparece uma segunda "maçã".
estoque["maçã"]
Lê o valor da chave.

$ ./estoque

Três produtos: maçã, banana, pera. As chaves não se repetem, então size() é o número de produtos diferentes.

2. Outras formas de inserir: insert e emplace

#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> estoque{{"maçã", 12}};

    estoque.insert({"uva", 40});
    estoque.emplace("kiwi", 5);

    auto [pos, inseriu] = estoque.insert({"maçã", 99});
    std::cout << std::boolalpha << "inseriu? " << inseriu << '\n';
    std::cout << "maçã continua com " << pos->second << '\n';

    estoque.insert_or_assign("maçã", 99);
    std::cout << "agora maçã tem " << estoque["maçã"] << '\n';

    for (const auto& [nome, qtd] : estoque) {
        std::cout << nome << ": " << qtd << '\n';
    }
}

Insere o par só se a chave ainda não existe.

O mesmo que o insert, mas você passa a chave e o valor soltos, e o par é construído direto dentro do map, sem cópia intermediária.
auto [pos, inseriu] = estoque.insert(…);
O insert devolve duas coisas: um iterador para o par (o novo ou o que já estava lá) e um bool dizendo se inseriu. Os colchetes desmontam essa dupla em duas variáveis (veja a seção 4).
pos->second
O iterador aponta um par. ->first é a chave e ->second é o valor. A setinha é o mesmo que (*pos).second.
insert_or_assign
"Insere ou atribui" C++17: insere se não existe, troca se existe. Faz o mesmo que estoque["maçã"] = 99, mas diz a intenção no nome.
FormaChave novaChave que já existeQuando usar
m[chave] = valor;CriaTroca o valorO jeito do dia a dia: "o estoque de pera agora é 8".
m.insert({chave, valor});CriaNão mexe (devolve false)Quando o valor antigo deve ser preservado: "cadastre se ainda não existir".
m.emplace(chave, valor);CriaNão mexeIgual ao insert, um pouco mais eficiente com valores grandes.
m.insert_or_assign(chave, valor);CriaTrocaIgual ao [], mas explícito; funciona também com valores que não têm construtor vazio.

3. Ler com []: a chave criada sem querer

O [] tem uma regra que pega todo mundo: se a chave não existe, ele a cria, com o valor "vazio" do tipo (0 para int, "" para std::string). Isso vale até quando você só queria olhar:

#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> estoque{{"maçã", 12}, {"pera", 8}};

    std::cout << "Produtos: " << estoque.size() << '\n';

    if (estoque["uva"] > 0) {
        std::cout << "Tem uva!\n";
    }

    std::cout << "Produtos: " << estoque.size() << '\n';
    for (const auto& [nome, qtd] : estoque) {
        std::cout << nome << ": " << qtd << '\n';
    }
}

$ g++ -std=c++23 -Wall -Wextra criar-sem-querer.cpp -o criar-sem-querer
$ ./criar-sem-querer
Produtos: 2
Produtos: 3                « a pergunta "tem uva?" cadastrou a uva!
maçã: 12
pera: 8
uva: 0

A Ana só perguntou se havia uva, e o estoque ganhou um produto "uva" com quantidade 0. Num relatório, isso aparece como um produto que a loja nunca vendeu. É por isso que o [] é ótimo para escrever e perigoso para ler. Para ler, use at ou find/contains.

Pelo mesmo motivo, o [] não funciona num map const: como ele pode criar chaves, ele muda o map, e um map constante não pode mudar. Veja em "Quando dá errado".

4. Ler com segurança: at, find e contains

at: lê ou lança uma exceção

O at é a escolha quando a chave tem que existir: se não existe, é um erro, e é melhor parar do que seguir com um 0 inventado. Se quiser tratar o erro, use try/catch:

#include <iostream>
#include <map>
#include <stdexcept>
#include <string>

int main() {
    std::map<std::string, int> estoque{{"maçã", 12}, {"pera", 8}};

    try {
        std::cout << "Uvas: " << estoque.at("uva") << '\n';
    } catch (const std::out_of_range& e) {
        std::cout << "Erro: " << e.what() << '\n';
    }
    std::cout << "Produtos: " << estoque.size() << '\n';
}

$ g++ -std=c++23 -Wall -Wextra at-try.cpp -o at-try

5. Percorrer em ordem: for (const auto& [nome, qtd] : estoque)

Cada item de um map é um par (std::pair), com .first (a chave) e .second (o valor). Há duas formas de percorrer:

// forma 1: structured bindings (C++17)
for (const auto& [nome, qtd] : estoque) {
    std::cout << nome << ": " << qtd << '\n';
}

// forma 2: o par inteiro
for (const auto& par : estoque) {
    std::cout << par.first << ": " << par.second << '\n';
}
[nome, qtd]
Structured bindings ("ligações estruturadas") C++17: desmonta o par em duas variáveis com nomes que você escolhe. Muito mais legível que .first/.second. A aula pair, tuple e Desestruturação conta mais.
const auto&
Sem cópia e sem mudar. Se quiser mudar as quantidades no laço, use auto& [nome, qtd] e escreva em qtd. A chave nunca pode ser mudada (ela é const dentro do par), senão a ordem se quebraria.

A ordem é sempre a das chaves, do menor para o maior: para textos, a ordem alfabética (com um detalhe: maiúsculas vêm antes das minúsculas, e letras acentuadas no começo, como em "água", vão para o fim, porque o map compara os bytes do texto; veja Acentos e UTF-8). Para números, a ordem crescente. Se a ordem não importa, existe o std::unordered_map.

6. Apagar com erase

#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> estoque{{"maçã", 12}, {"pera", 0}, {"uva", 40}};

    auto apagados = estoque.erase("pera");
    std::cout << "apagados: " << apagados << '\n';
    std::cout << "apagados: " << estoque.erase("melão") << '\n';

    for (auto it = estoque.begin(); it != estoque.end(); ++it) {
        std::cout << it->first << " = " << it->second << '\n';
    }
}

$ g++ -std=c++23 -Wall -Wextra apagar.cpp -o apagar
$ ./apagar
apagados: 1
apagados: 0                « apagar uma chave que não existe não é erro
maçã = 12
uva = 40

erase(chave) devolve quantos itens apagou (0 ou 1). Também existe erase(iterador), que, como no vector, devolve o iterador do próximo (aula Iteradores), e std::erase_if(estoque, …) C++20 para apagar todos os que cumprem uma condição. No map, apagar um item só invalida o iterador dele.

7. O clássico: contar palavras

O [] que cria chaves com 0 é perfeito para contar: ++contagem[palavra] funciona tanto na primeira vez (cria com 0 e soma 1) quanto nas seguintes (soma 1).

#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> contagem;
    std::string palavra;

    while (std::cin >> palavra) {
        ++contagem[palavra];
    }

    for (const auto& [p, vezes] : contagem) {
        std::cout << p << ": " << vezes << '\n';
    }
}

$ g++ -std=c++23 -Wall -Wextra contar.cpp -o contar
$ echo "o gato e o rato e o queijo" | ./contar
e: 2
gato: 1
o: 3
queijo: 1
rato: 1
while (std::cin >> palavra)
Lê uma palavra por vez (o >> separa nos espaços) até a entrada acabar (aula Entrada com cin).
++contagem[palavra];
Se a palavra é nova, o [] cria com 0 e o ++ deixa 1. Se já existe, só soma 1.
echo "…" | ./contar
No terminal, o | manda o texto do echo para a entrada do programa.

Em quatro linhas de lógica: cada palavra uma vez só, com a contagem, em ordem alfabética. Esse é o tipo de problema em que o map brilha.

Quando dá errado

Apareceram produtos com quantidade 0 que ninguém cadastrou

O que significa: algum lugar do programa leu com m[chave] uma chave que não existia, e o [] a criou.

Como consertar: para ler, use contains, find ou at. Deixe o [] para escrever.

terminate called after throwing an instance of 'std::out_of_range' / what(): map::at

O que significa: um at(chave) não achou a chave, e ninguém pegou a exceção.

Como consertar: confira antes com contains, ou envolva com try/catch (const std::out_of_range&). Se a chave deveria existir, o erro está em quem esqueceu de cadastrá-la.

error: passing ‘const std::map<…>’ as ‘this’ argument discards qualifiers

O que significa: a função recebeu o map como const std::map<…>& (só leitura) e usou [], que pode criar chaves, ou seja, mudar o map. Como consertar: dentro da função, leia com estoque.at("maçã") ou com find. Não tire o const do parâmetro só para o [] funcionar.

error: ‘class std::map<…>’ has no member named ‘contains’

O que significa: compilou com um padrão anterior ao C++20.

Como consertar: -std=c++23, ou m.count(chave) > 0.

Resumo

  • std::map<Chave, Valor> guarda pares chave → valor, com chaves únicas, sempre em ordem de chave.
  • Escrever: m[k] = v (cria ou troca), insert/emplace (só cria), insert_or_assign (cria ou troca).
  • Ler: m[k] cria a chave se ela não existe; at lança std::out_of_range; contains C++20 e find só perguntam.
  • Percorrer: for (const auto& [nome, qtd] : m).
  • Apagar: m.erase(k), que devolve 0 ou 1.
  • Contar: ++contagem[palavra].
  • Próximo passo: a versão sem ordem e mais rápida, std::unordered_map.
